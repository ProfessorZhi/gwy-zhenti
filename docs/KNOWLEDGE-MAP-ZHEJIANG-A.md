# 浙江省考 A 类行测知识地图（v0.1）

> 目标：把行测从“六大模块目录”展开为可持续维护的知识树。每道真题都能落到具体节点，逐步积累题型、考点、方法、错因和掌握度。
>
> 适用范围：以浙江省考综合类 A 卷为主；兼容 2008 年以来的历史真题。此图是学习分类框架，不是官方公布的完整考点清单。

## 0. 考试口径

- 浙江省考《行政职业能力测验》官方大纲：客观题，120 分钟，满分 100 分。
- 官方公布六个考查部分，但没有公布六大模块的固定分值或每道题的统一分值。**题量占比不能直接当成分值占比。**
- 以仓库 2026 年浙江 A 类回忆版为例：120 题，政治理论 10、常识判断 10、言语理解 25、数量关系 20、判断推理 40、资料分析 15。
- 2026 年实际考试的数量关系没有数字推理，20 题均为数学运算；数字推理保留在历史知识树中，用于学习 2008—2025 年等历史试卷。不要把“2026 年未考”误写成“永久取消”。

## 2. 模块知识树

### 1. 政治理论

**核心能力：** 理解党的创新理论、党和国家方针政策，并能识别重要论述、会议文件及政策之间的关系。

- 1.1 理论基础
  - 马克思主义哲学基础
    - 唯物论、辩证法、认识论、历史唯物主义
    - 人与自然、实践与认识、联系与发展
  - 习近平新时代中国特色社会主义思想
    - 核心要义、世界观和方法论
    - 重要理念、原创性概念
- 1.2 党史与重要历史节点
  - 党的重要历史时期、重大事件、重要会议
  - 新中国史、改革开放史、社会主义发展史
- 1.3 重要会议与文件
  - 党代会、中央全会、全国两会
  - 五年规划、重要决定、重要建议
  - 文件提出时间、主要内容、政策目标
- 1.4 国家治理与政策领域
  - 经济建设、改革开放、高质量发展
  - 政治建设、全面依法治国
  - 文化建设、社会建设、人口发展
  - 生态文明、农业农村、乡村振兴
  - 国防和军队建设、外交与全球治理
  - 科技创新、数字经济、人工智能
- 1.5 时政与重要讲话
  - 年度重要时政
  - 重要会议讲话、贺词、考察讲话
  - 全球倡议、国际组织与国际合作
- 1.6 常见设问形式
  - 表述正误判断
  - 多项表述组合判断
  - 会议、文件、讲话与内容对应
  - 重要论述的时间排序

### 2. 常识判断

**核心能力：** 调用跨学科基础知识，识别事实、概念、规则及其适用条件。

- 2.1 法律
  - 宪法与国家机构
  - 民法典：民事主体、物权、合同、人格权、侵权责任
  - 行政法：行政许可、行政处罚、行政复议、行政诉讼
  - 刑法基础
  - 经济法与市场监管：反不正当竞争、消费者权益、知识产权
  - 劳动与社会保障、人事档案和公共服务相关规定
- 2.2 经济
  - 宏观经济：GDP、就业、物价、消费、投资、贸易
  - 财政与货币政策
  - 市场机制、供求、价格、竞争
  - 收入分配、产业结构、区域经济
- 2.3 管理与公共管理
  - 行政管理、公共服务、组织管理
  - 决策、执行、监督、绩效
  - 应急管理与基层治理
- 2.4 科技与自然科学
  - 物理：力学、光学、热学、电磁、天文
  - 化学：物质性质、反应、材料、食品添加剂
  - 生物：人体、遗传、生态、农业生物
  - 信息科技：人工智能、计算机、通信、量子信息
  - 工程与新材料、能源、交通技术
- 2.5 历史
  - 中国古代史、近现代史
  - 世界史与重大历史事件
  - 制度、科技、社会生活史
- 2.6 人文与文化
  - 文学、诗词、典籍、作家作品
  - 艺术、建筑、书画、音乐
  - 传统节日、礼仪、服饰、民俗
  - 哲学思想与文化常识
- 2.7 地理与国情
  - 中国自然地理、行政区划
  - 世界地理、气候、地形、资源
  - 中国区域地理与重要城市
  - 浙江省情：地市、地形、河流、产业、物产、文化
- 2.8 生活常识
  - 食品与营养、日常化学
  - 交通、安全、消防、环境
  - 常见生活现象及其科学原理

### 3. 言语理解与表达

**核心能力：** 准确理解词句和篇章，识别语境、逻辑关系、作者意图及文本结构。

- 3.1 逻辑填空
  - 实词辨析：词义、搭配对象、程度轻重、感情色彩
  - 成语辨析：含义、适用对象、语体、褒贬
  - 语境分析：上下文呼应、解释说明、对照
  - 逻辑关系：并列、递进、转折、因果、条件、让步
  - 混搭填空：实词与成语组合
- 3.2 片段阅读
  - 中心理解、主旨概括
  - 意图判断、标题选择
  - 细节判断、信息查找
  - 推断下文、隐含信息
  - 作者态度、观点倾向
  - 论证结构、例证作用、原因分析
- 3.3 语句表达
  - 语句排序
  - 句子填空：段首、段中、段尾
  - 语句衔接与连贯
  - 病句、歧义及表达规范（以当年真题实际考查为准）
- 3.4 篇章阅读
  - 篇章主旨与结构
  - 段落关系、上下文定位
  - 细节理解、词句理解
  - 作者意图、推断判断

### 4. 数量关系

**核心能力：** 把文字条件转化为数量关系、方程或数学模型，并快速计算。

#### 4.1 数学运算（当前浙江 A 类重点）

- 4.1.1 基础数量关系
  - 和差倍比、比例、平均数
  - 方程与不定方程
  - 集合与容斥、盈亏问题
- 4.1.2 工程与效率
  - 工作总量、工作效率、合作与轮流
- 4.1.3 行程问题
  - 相遇、追及、往返
  - 流水行船、环形路线
  - 分段运动、休息与变速
- 4.1.4 经济利润
  - 成本、售价、利润率
  - 折扣、配套销售、多方案定价
- 4.1.5 浓度与混合
  - 溶液浓度、溶质守恒
  - 混合、蒸发、加水
- 4.1.6 排列组合与概率
  - 分类与分步计数
  - 相邻、不相邻、捆绑、插空
  - 排列、组合、限制条件
  - 古典概率、互斥与独立
- 4.1.7 几何问题
  - 平面几何：三角形、圆、面积、周长
  - 立体几何：长方体、正方体、体积、表面积
  - 勾股关系、相似、比例
- 4.1.8 数论与整数
  - 奇偶、整除、余数
  - 最大公约数、最小公倍数
  - 质数、因数、倍数
- 4.1.9 日期、周期与时间
  - 星期日期、周期循环
  - 轮班、重复事件、周期余数
- 4.1.10 最值与构造
  - 极端值、最不利/最有利
  - 构造数列、抽屉原理
  - 排序约束、边界分析

#### 4.2 数字推理（历史题型分支）

> 2008 年浙江统考等历史试卷包含数字推理；2026 年浙江 A 类回忆版没有该题型。保留本分支用于历史真题学习，不把它标成 2026 年现考题型。

- 4.2.1 等差与等比数列
- 4.2.2 多级差分：一次差、二次差、逐级差分
- 4.2.3 递推数列：前项递推、前两项/多项递推
- 4.2.4 交替与分组：奇偶项、周期项、分组规律
- 4.2.5 幂次数列：平方、立方、变形幂次
- 4.2.6 特殊数列：质数、合数、阶乘、斐波那契
- 4.2.7 组合规律：加减乘除、数字拆分、位数特征

### 5. 判断推理

**核心能力：** 识别客观对象之间的关系，理解概念，进行形式推理和论证评价。

#### 5.1 图形推理

- 5.1.1 位置规律：平移、旋转、翻转、相对位置
- 5.1.2 样式规律：叠加、相加、相减、求同、求异
- 5.1.3 属性规律：对称、曲直、开闭、连接方式
- 5.1.4 数量规律：点、线、角、面、素、部分数
- 5.1.5 黑白块与颜色规律
- 5.1.6 特殊规律：图形间关系、功能元素、路径
- 5.1.7 空间重构：折纸盒、多面体折叠、立体拼合、三视图

#### 5.2 类比推理

- 5.2.1 逻辑关系：全同、并列、包含、交叉
- 5.2.2 对应关系：工具与用途、材料与成品、主体与对象
- 5.2.3 因果关系、条件关系、功能关系
- 5.2.4 语义关系：近义、反义、象征、引申
- 5.2.5 语法关系：主谓、动宾、偏正、并列
- 5.2.6 词项与常识关系：组成、职业、地点、属性

#### 5.3 定义判断

- 5.3.1 单定义与多定义
- 5.3.2 提取定义要件：主体、对象、条件、方式、目的、结果
- 5.3.3 关键限定词：必须、可以、只有、同时、至少
- 5.3.4 正例与反例识别
- 5.3.5 定义应用：法律、管理、心理、经济、科技、社会生活

#### 5.4 逻辑判断

- 5.4.1 形式逻辑
  - 充分条件、必要条件、逆否关系
  - 联言、选言、假言、否定
  - 全称、特称与量词
- 5.4.2 真假推理
  - 矛盾关系、反对关系
  - 多人陈述、真假数量约束
- 5.4.3 分析推理
  - 排列、排序、分组、匹配
  - 位置、对应、条件约束
- 5.4.4 论证推理
  - 加强、削弱
  - 前提假设、必要条件
  - 解释原因、评价论证
  - 论点、论据、论证方式
- 5.4.5 推理形式与逻辑谬误
  - 类比论证、因果推断
  - 滑坡谬误、以偏概全、偷换概念等

### 6. 资料分析

**核心能力：** 从文字、表格、图形中定位数据，识别统计指标，列式并快速估算。

- 6.1 材料类型
  - 文字型资料
  - 统计表
  - 柱状图、折线图、饼图
  - 混合型与多材料综合
- 6.2 基础统计概念
  - 基期、现期
  - 同比、环比
  - 增长量、增长率
  - 比重、平均数
  - 倍数、贡献率、拉动
- 6.3 核心题型
  - 基期量与现期量
  - 增长量计算
  - 增长率计算与比较
  - 两期比重、比重变化
  - 平均数与平均数增长
  - 倍数与倍数比较
  - 综合分析、判断正误
- 6.4 计算方法
  - 直接查数与简单计算
  - 截位直除、首数法
  - 特征数字、有效数字
  - 百分数与分数互化
  - 估算、比较与差分
- 6.5 易错点
  - 单位与量纲
  - 时间口径、统计范围
  - 基期/现期混淆
  - 百分点与百分比混淆
  - 增长率和增长量混淆

## 4. 真题入图规则

每道题尽量记录以下字段：

| 字段 | 示例 |
| --- | --- |
| 年份 / 卷别 | 2026 / 浙江 A 类 |
| 一级模块 | 数量关系 |
| 二级领域 | 数学运算 |
| 三级题型 | 行程问题 |
| 四级考点 | 相遇、追及、分段运动 |
| 核心方法 | 设速度、列相对路程关系 |
| 题目来源 | 仓库文件与题号 |
| 错因 | 概念不清 / 建模错误 / 计算错误 / 时间不足 |
| 掌握状态 | 未学 / 学习中 / 已掌握 / 需复习 |

### 建议的学习状态

- 未学：尚未系统学习。
- 学习中：知道基本概念，但还不能稳定独立解题。
- 已掌握：能独立识别题型并稳定解题。
- 需复习：曾经掌握，但近期练习出现遗忘或错误。

### 后续迭代原则

1. 先按六大模块建立稳定的一级、二级结构。
2. 做真题时再根据真实题目补充三级题型和四级考点，不为追求树的完整而臆造考点。
3. 同一题可以关联多个知识点，但只指定一个主分类，避免统计重复。
4. 对每个节点积累真题数量、正确率、平均耗时、常见错因和复习状态。
5. 历史题型与当前题型分开标记：例如数字推理保留在历史分支，不与 2026 年现考题量混算。
6. 每年根据新真题调整题型状态；考试大纲未明确、回忆版证据不足的内容标记为“待核验”。

> 这张地图是学习导航和真题索引的骨架。后续应由真实题目不断校准，而不是一次性把所有可能考点全部塞入。
