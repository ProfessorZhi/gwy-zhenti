## 1. 目标

**最终目标**：2016 年起（并持续吸收今后新增年份）的**行测与申论**真题，覆盖**国考与全部省级地区**。

**优先级**（D5）：先保证**每个省级地区都有可读、可核验的卷**，再向老年份与更多年份纵深。

**里程碑**：

- **M1（先行）** **段一接入全部候选源**（行测 + 申论，只产清单、不产正文），并让**行测 2016–2026 端到端跑通** —— 目的是**验证整条管线**并**拿到完整目标域的真实缺口图**（没有全量清单就排不出「地区优先」），不是宣称覆盖完整。
- **M2** 行测补省份缺口 —— 按 `gaps.md` 的地区维度缺口逐省补齐。
- **M3** 申论 —— 申论整卷完整性是已知最大缺口，单独一章推进。
- **M4** 增量常态重跑 —— 上游更新或出现新源时，adapter 重跑、幂等导出。

## 2. 非目标（本设计明确不做）

- **不做 OCR / 转写**：上游已有正文，转写只会引入错误。
- **不从 PDF 重转**：M1–M3 一律用已有 Markdown 源；历史 PDF（如 `Yaoyuan-Zhang319`）仅作**争议题原件对照**，不批量重转。
- **不改写题干 / 选项 / 答案 / 解析**：除 §6 的五项机械变换外零改写。
- **不做答案投票**：多源答案冲突时留证，不按多数假设计正确。
- **不并入非国省考**：选调、司法所、法检、事业编、模考、公开课习题一律排除。

## 4. 架构：两段式

```
上游仓（只读克隆）                     产物
  ERRRC/xingcezhenti      ┐
  linfukai186/gongkao-tiku ├─► [段一 归并] ─► work/catalog/     ← 只出清单，不碰正文
  (M3) 申论源 …            ┘                       │
                                                  │ catalog.jsonl（唯一接口）
                                                  ▼
                                        [段二 导出] ─► gwy-zhenti/国考/<年>/行测-<卷型>.md
                                                        gwy-zhenti/省考/<省>/<年>/行测-<卷型>.md
                                                        gwy-zhenti/图片/<卷标识>/{题目,公式}/
```

- **段一可独立验收**（你审清单）；**段二可重跑**（幂等）。
- 加新源只需**新增一个 adapter**，下游不动。

## 5. 段一：卷键、adapter、产物

### 5.1 卷键

归一身份：`(层级, 地区, 年份, 科目, 卷型[, 变体])`，层级 ∈ {国考, 省考}，科目 ∈ {行测, 申论}。
**原始卷名另行保真保存**，不因归一而丢失。

### 5.2 adapter 输出（同构记录）

| 字段 | 含义 |
|---|---|
| `卷键` / `原始卷名` | 归一身份 / 源里的原标题（逐字节保真） |
| `来源家族` | `ERRRC` / `linfukai186` / … |
| `正文` | 有 / 无（adapter 实测，不采信 README 自报） |
| `图片` | 题目图 N 张 / 公式图 M 张 / 缺失 |
| `性质` | 真实考试 · 联考 · 单独命题 · 网友回忆版 · 精选 · 非国省考 |
| `文件` | 该卷在源里的模块文件清单（供段二使用） |

### 5.3 产物（`work/catalog/`）

| 文件 | 内容 |
|---|---|
| `catalog.jsonl` | 每卷一行，段二唯一输入 |
| `coverage.md` | **地区 × 年份** 覆盖矩阵，标注 单源 / 多源 / 缺；按 D5 以**地区维度优先**呈现 |
| `gaps.md` | 缺口清单，**排序 = 地区优先、年份次之、新卷先于老卷** |
| `conflicts.md` | 同卷多源不一致项，留证不裁决 |
| `excluded.jsonl` | 被排除项及**排除理由**（可审计） |
| `unparsed.jsonl` | 解析不了的卷名 —— **一条不漏，绝不静默丢弃** |

**段一绝不写 `gwy-zhenti` 正文。**

段一在 M1 即**接入全部候选源**（含申论源），只产清单 ⇒ `coverage.md` 从一开始就是**完整目标域**的缺口图，M3 只是把已 catalog 的申论卷导出，**不需重做段一**。

## 6. 段二：导出时的五项变换

1. **合并**：按模块顺序把该卷的各模块文件拼成一卷。
2. **题号重建**：模块题数累加得连续原卷题号。
   - 当年**模块顺序表**查得到 → frontmatter 标 `题号口径: 原卷重建`；
   - 查不到 → 保留模块分节 + 模块内题号，标 `题号口径: 模块内序号`。
3. **答案去泄露**：剥离选项行上的 `✅`；答案与解析移到卷末独立板块（`<details>` 折叠），满足 `QUALITY.md`「避免读题时提前泄露答案」。
4. **图片重写**：**只复制被引用的图**（非 39k 全量），路径指向 `图片/<卷标识>/{题目,公式}/<hash>.png` 的**相对路径，按该文件所在目录深度计算**（国考卷 2 级 ⇒ `../../`；省考卷 3 级 ⇒ `../../../`），**不写死**。
5. **frontmatter**：按 `QUALITY.md` 契约生成（考试 / 地区 / 年份 / 科目 / 卷型 / 真题性质 / 来源[] / 校验状态）。

**卷标识**：确定性 slug，如 `2016-浙江-行测-A类`。

**除此之外，题干 / 选项 / 答案 / 解析逐字节来自源。**

### 6.1 解析表（**已实测降险**）

2026-10-09 对 `ERRRC/xingcezhenti` 实测后**修正**：该源 frontmatter **已给出归一字段**
（`试卷` / `地区` / `年份` / `模块` / `题数`），故**「地区别名表」不需要了**。实际只需：

- **层级判定**：`地区 == "国考"` → 国考；其余为省考。
- **卷型归一表**（从 `试卷` 名抽取，**只归一到已声明词表**）：`A类 / B类 / C类 / D类 / 乡镇卷 / 县级卷 / 副省级 / 地市级 / 行政执法`；
  另需识别 `网友回忆版`（性质）、`精选`（性质）、`联考`（命题形式）。无后缀 ⇒ `统考`。

  **2026-10-09 实测修正（推翻「词表很小」的原判）**：全库 515 卷的括号后缀实测有 **约 25 种**，
  远超原词表。`A类 154 / B类 142 / C类 90 / 乡镇卷 41 / 下半年 37 / 县级卷 29 / 乡镇 17 / 地市级 10 /
  浙江A卷 10 / 浙江B卷 10 / 甲级 6 / 乙级 6 / 公检法卷 6 / 省级 6 / 省直 6 / 黑龙江省直卷 6 /
  黑龙江县乡卷 6 / 江西县级以上 6 / 山西县级+乡镇 6 / 县级+乡镇 6 / 单考区卷 6 / 县乡卷 5 /
  定向乡镇 5 / 县级以上 5 / 河南省县级以上 5 / 区级及以上卷 12 / 县级、乡镇统一卷 12 / A卷 6 / B卷 6 …`
  另加各省 `（X卷）` 地区标记（`四川卷 22 / 新疆卷 24 / 内蒙古卷 17 …`，**不是卷型**）。

  **规则（不可放宽）**：括号后缀先剥地区标记；剩下的是已声明词表内的 —— 含**仅多一个尾缀「卷」**的情形
  （`行政执法卷`→`行政执法`）—— 归一；**否则逐字带上进 `ptype`**，**绝不默认成 `统考`**。
  尾缀「卷」的容差**只在剥掉后能落回词表时才生效**：真库同时存在 `（省直）` 与 `（黑龙江省直卷）`，
  宽泛地剥会让两者收敛成同一个 `ptype` ⇒ 撞 slug ⇒ 丢卷。
  理由不是洁癖：`（浙江A卷）` 与 `（浙江B卷）` 同年同省同科目，若都默认成 `统考`，
  两卷会算出**同一个 slug**，段二导出时后写覆盖先写 —— 直接丢卷。
  `网友回忆版/精选/联考` 属性质与形式，**在 token 内部剔除**（复合后缀如 `（副省级网友回忆版）` 里
  它们只是尾巴，按整个 token 精确匹配会漏 ⇒ 性质词被带进 slug），不进 `ptype`。
- **模块顺序**：即目录前缀 `01-政治理论 … 06-资料分析`；「2025 起国考新增政治理论在最前」已由该序覆盖。

**需排除**（实测存在）：`地区 ∈ {选调, 深圳市考, 广州市考}`；`试卷` 名含 `选调/法检/公检法/司法所/事业编/职测/综应/模考`。
规则**只做保守命中**；拿不准的一律进 `unparsed.jsonl` 等你裁决，**不猜**。

## 7. 验收闸门

| 闸 | 判据 |
|---|---|
| **G1 卷完整** | 卷内题数 == 各模块 frontmatter 题数之和；题号连续无缺无重 |
| **G2 图片完整** | md 里每个 `src=` 都真实存在；反向：复制的图都被引用（双向） |
| **G3 答案不泄露** | 正文选项行无 `✅`；每卷有独立答案板块 |
| **G4 幂等** | 重跑导出，输出文件 sha 不变 |
| **G5 保真** | 扣除五项变换后与源**逐字节一致**（用 diff 证明，不靠口头） |
| **G6 覆盖账** | 覆盖率**由 catalog 计算得出**并如实写入；「已入库」只能指通过 G1–G5 的卷 |

## 9. 诚实边界（事前明写）

- **ERRRC 自报 515 卷，不等于入库 515 卷** —— 其中含选调、精选等非国省考项，实际入库数**必定更小**；数字以 catalog 计算为准。
- **`linfukai186` 是题级 JSON、不是卷**，与 ERRRC 的卷对齐靠匹配规则，**会有误配** —— 故它只用于覆盖对照与补洞提示。
- **申论整卷完整性是最大缺口**，M3 前不宣称申论覆盖。
- **模块顺序表与地区别名表**为人工维护，未覆盖的年份/地区**如实降级**，不猜。
- **公式是位图不是数学表达式**（源里 TeX 已丢），`QUALITY.md` 的「规范数学表达」在本批**无法达成**，以位图保真替代。
- 本仓私有；来源与再分发权限**逐卷登记**，不因 GitHub 公开可访问即视为可转载。
