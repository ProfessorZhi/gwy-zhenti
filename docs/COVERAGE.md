# 覆盖报告

数据来自 `catalog/manifest.jsonl`，逐卷一行；**槽位** = 去重后的 `(地区, 年份, 科目, 归一化卷型)`。同一槽位可能有多份文件（重复采集或多来源），因此文件数 ≥ 槽位数。

本页统计库内文件的分布（地区、年份、科目、卷型）。**应有试卷、收录率与缺口以 [缺口总账](GAP-STATUS.md) 为准**，本页不重复计算。

## 统计口径

- **2016–2026 年**：按实际举行的考试逐卷登记于 [槽位台账](../catalog/exam-slots.jsonl)，每份应有试卷为已收录、缺卷或无独立考试之一，并附依据；应有试卷 = 已收录 + 缺卷。
- **2008–2015 年**：只统计已收录试卷（405 份），不判定缺卷。
- **专项收录**：公安招警和公检法（公安院校联考、政法干警等）9 份照常收录，不计入台账与缺口统计。
- **来源不作为分母**：粉笔为主要题源，华图与网络检索补充；同卷逐题取并集，每份试卷在 `来源清单` 中记录各来源及贡献范围，详见 [文档格式](SCHEMA.md)。

## 台账与来源追溯
