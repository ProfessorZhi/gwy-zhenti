# 覆盖报告

统计口径：`catalog/manifest.jsonl` 逐卷一行；**槽位** = 去重后的 `(地区, 年份, 科目, 归一化卷型)`。同一槽位可能有多份文件（重复采集或多来源），因此文件数 ≥ 槽位数。

快照时间：2026-11-03。

> **覆盖范围不等于内容完整度。** 当前确认 A1 缺原题 **280 题位**、A2 缺选项 **6 题位**、B2 缺参考答案 **7 题位**；按文件题号去重后为 **293 个明确缺项题位**，并非完整率认证，见 [缺口总账](GAP-STATUS.md)。**图片引用已完成对账**：按当前 `catalog/manifest.jsonl` 全部卷的 `image_references` 求和为 **19,345**，与 [质量汇总](../reports/QUALITY-SUMMARY.json) 相同（2026-11-03 删除广东目录下 9 份与 `省考/广州/` 粉笔版重复的广州市考旧卷后重算）。

## 阅读本报告前：唯一的真实考试全量口径

**2008–2015 仅统计当前存量：405 个 MD 文件 / 392 个归一化卷型槽位（行测 226、申论 179），不再以粉笔目录或其他目录推算历史应有总数。**

**2016–2026 按所有真实考试建立独立基线**：当前 1,269 个 MD 文件 / 1,260 个槽位（行测 509、申论 760）；旧占位 23 个未收、18 个身份待核、重点地区另外 8 个年度科目格待核。初步查到的招录公告另明确至少 **28 个尚未归档的卷型位置**（部分与旧待核重合），详见 [真实考试全量卷次覆盖](COVERAGE-ALL-EXAMS.md)。**全国应有卷数的精确分母仍未建成，不能发布全国覆盖率。**

**来源不作为分母**：粉笔为主要题源，华图作为补充及交叉核对；同卷逐题并集，保留每份试卷的各来源及贡献范围，来源并集不等于多个独立卷次。详见 [来源字段规范](SCHEMA.md)。
