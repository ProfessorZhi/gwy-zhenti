>
> 本库清单基线：`main` 的 `catalog/manifest.jsonl`（2026-11-03，1,674 文件）；原有缺卷占位 `资料缺失/INDEX.jsonl`、`reports/PRIORITY-MISSING.json`；粉笔目录基线为行测 `catalog-live-20261019`、申论 `shenlun-catalog-20261021` 的**历史快照**。后续变动需重新核算，不能沿用百分比。

## 统计规则

- **2015 年及以前**：只列已经归档的历史存量，不用粉笔目录推算「应有总数」，也不设自动追缺或完成率。
- **2016–2026 年**：第一套按实际发生的国考、省考、独立市考及可区分的选调/专项考试，使用当年考试公告、试卷目录、考试科目和卷型证据建立独立的「应有卷次」底账。以 `地区 × 考试年度 × 考试/场次 × 科目 × 实际独立卷型` 为判据；同日联考不跨地区互相替代，共用题不视为整卷重复。未证明开考的不自动算缺卷。
- **粉笔对照**另列目录匹配率，允许精确源 ID 和明确标示的规范名回退；目录没出现但实际开考的卷**仍是全国口径的候选缺卷**。
- 「卷次槽位」按现有 `tools/coverage_stats.py::norm_pt` 归一化，**只是仓库既有文件的去重口径**，尚未含所有缺卷与考试场次。应有卷次总数**目前尚未逐年逐省核定，不能给全国完整率**。
- 现有 MD 的题号、答案块或图片均不等于逐题验真；另见 [缺口总账](GAP-STATUS.md) 与 [质量标准](QUALITY-STANDARD.md)。

## 下一轮全量基线的判定边界

1. 以官方招录公告、考试大纲、笔试安排为优先证据逐年逐省列出真实举办的考试、行测/申论及各卷型；明确是否是独立招录场次、专科/特殊职位、独立市考、选调及联考。**不能用另一科目或邻年推断就判定具体卷型必然存在。**
2. 每个候选分别记：考试身份已证、卷型独立性已证、原卷已找到、仓库已归档、来源范围内容完整、质量核验。证据仅证明考试举行时，状态是「缺卷候选 / 待取原题」，不能声称找到真题。
3. 不将模考、事业单位考试、专业科目混入行测/申论的主要分母。专项公务员考试按**独立场次**另开对应行，不能简单与一般省考合并或重复记数。
4. [原占位 23/18](../资料缺失/README.md) 与 [重点地区 8 格](../reports/PRIORITY-MISSING.json) 是**旧工作台账**；本轮官方新证据说明其中部分「身份待核」已经可以收敛，但正式更改占位/Issue 前应同时维护其生成脚本及引用，避免文档与机器清单漂移。
5. [当前 293 处明确内容缺项](GAP-STATUS.md) 与上述整卷缺位是不同单位；不得相加当作「缺多少份试卷」。不存在一个已核实的「全国应有试卷准确总数」，所以暂不发布全国覆盖百分比。
