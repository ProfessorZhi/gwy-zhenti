# 质量报告

一句话结论：**逐题比对 1,185 份卷、约 6.5 万道题，没有发现题目缺失、选项缺失、答案缺失、断图或错字。**剩下的问题集中在两类：排版差异（已修）和少量「考点 / 来源」元数据未渲染（已定位，正在补）。

审计快照：2026-10-23。

---

## 审计方法

不是抽查，是**确定性全量比对**：

```mermaid
flowchart LR
    A[manifest.jsonl<br/>1,422 份] --> B{有本地采集缓存?}
    B -->|1,185 份| C[逐题对齐<br/>document.json ↔ MD]
    B -->|28 份| D[无缓存<br/>第三方源，无法对源核验]
    C --> E[题面 / 选项 / 答案 / 解析<br/>逐字段比对]
    C --> F[图片引用<br/>逐路径存在性检查]
    C --> G[字符级 diff<br/>错字检测]
    E --> H[异常分桶]
    F --> H
    G --> H
```

对齐规则：

1. 把两侧文本归一化：去 Markdown 转义、去图片/链接语法、去 HTML 标签、`html.unescape`、NFKC、只保留汉字与字母数字。
2. 用 **4-gram 覆盖率** `cover(a, b)` 衡量「源内容有多少出现在 MD 里」；短于 4 字的串改用包含判定。
3. 覆盖率 < 0.9 记为待查，再按源文本长度、MD 长度分桶归因。

为什么要归一化：同一道题在网页上是 `<img latex=...>`，在 MD 里是图片链接；选项字母 A/B/C/D 在两侧的位置也不同。不归一化会把纯排版差异误判成内容缺失——第一版脚本的 27,391 条「异常」几乎全是这个原因。

## 题面覆盖率的归因

1,003 条待查全部做过归因，没有一条是正文丢失：

| 类别 | 数量 | 说明 |
| --- | ---: | --- |
| 覆盖率 0.85–0.9 | 772 | 选项字母位置、公式图片化、换行差异；内容一致 |
| 行测公式/图形题 | 132 | 源文本去掉公式图片后不足 40 字，覆盖率指标失真 |
| 行测其他 | 14 | MD 文本反而比源更长（多出作答要求/题型说明） |
| 申论旧格式 | 85 | 源 `prompt` 含整页答案 DOM，MD 只保留题干 |

「题面篇幅骤减 83 处」同理：旧申论采集把答案一起塞进了 prompt，渲染时正确拆到了答案区。MD 短是**对的**。

## 真实缺口：319 题缺「考点 / 来源」

这是本轮唯一确认的内容缺失。表现：

```text
源 explanationHtml:  参考答案说明…… 考点：提出对策类 来源：2016年国家公务员考试申论题（副省级）…（另有解析视频入口说明）
MD 解析区:           **解析状态：unknown（来源未提供）**
```

「参考答案说明」在 MD 里是有的（在答案区），丢的是 **考点** 与 **来源** 两行，以及「本题只提供解析视频、无文字解析」这一事实。

分布：74 卷 / 319 题，集中在 2016–2018 的国考与部分省考申论——**都是早期采集批次**，当时的字段映射没有把 `explanationHtml` 里的考点段拆出来。修复不需要重新访问题库，`document.json` 里原文都在。

> 修复顺序：先重排（本批），再补考点/来源（下一批），两批都刷新 `manifest.jsonl` 的 sha256。

## 复现

审计脚本不依赖网络，只读 `work/fenbi/` 的采集缓存与仓库 MD：

```bash
python3 tools/audit_fidelity.py --manifest catalog/manifest.jsonl --work <采集工作区>
```

输出逐卷 JSON（题数、异常分桶、图片计数），可再聚合成上表。
