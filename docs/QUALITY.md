# 质量报告

一句话结论：**逐题比对 1,185 份卷、约 6.3 万道题，没有发现题目缺失、选项缺失、答案缺失、断图或错字。**审计中发现的两类实质问题——题面被 `关联材料` 行割裂、319 题漏渲染「考点 / 来源」——本轮已全部修复并复核。

审计快照：2026-10-23（逐题比对）；图片转写复核：2026-10-27。

## 审计方法

不是抽查，是**确定性全量比对**：

```mermaid
flowchart LR
    A[manifest.jsonl<br/>1,213 份粉笔直采<br/>另有 209 份非粉笔源] --> B{有本地采集缓存?}
    B -->|1,185 份| C[逐题对齐<br/>document.json ↔ MD]
    B -->|28 份| D[无缓存<br/>粉笔来源但缓存缺失]
    C --> E[题面 / 选项 / 答案 / 解析<br/>逐字段比对]
    C --> F[图片引用<br/>逐路径存在性检查]
    C --> G[字符级 diff<br/>错字检测]
    E --> H[异常分桶]
    F --> H
    G --> H
```

对齐规则：

1. 把两侧文本归一化：去 Markdown 转义、去图片/链接语法、去 HTML 标签、`html.unescape`、NFKC、只保留汉字与字母数字。
2. 用 **4-gram 覆盖率** `cover(a, b)` 衡量「源内容有多少出现在 MD 里」；短于 4 字的串改用包含判定。
3. 覆盖率 < 0.9 记为待查，再按源文本长度、MD 长度分桶归因。

为什么要归一化：同一道题在网页上是 `<img latex=...>`，在 MD 里是图片链接；选项字母 A/B/C/D 在两侧的位置也不同。不归一化会把纯排版差异误判成内容缺失——第一版脚本的 27,391 条「异常」几乎全是这个原因。

## 题面覆盖率的归因

242 条待查全部做过归因，没有一条是正文丢失：

| 类别 | 数量 | 说明 |
| --- | ---: | --- |
| 申论旧格式 | 85 | 源 `prompt` 含整页答案 DOM，MD 只保留题干 |
| 行测公式/图形题 | 97 | 源文本去掉公式图片后不足 40 字，覆盖率指标失真 |
| 行测其他 | 60 | MD 文本不短于源，差异来自换行与附加说明 |

「题面篇幅骤减 85 处」同理：旧申论采集把答案一起塞进了 prompt，渲染时正确拆到了答案区。MD 短是**对的**。

## 本轮修复的两件事

### 1. 题面被 `关联材料` 行割裂（1,206 卷）

旧排版把全部材料堆在卷首，每道引用材料题在**题干与选项之间**插一行：

```markdown
2016年全球贸易总额约为多少万亿美元？

关联材料：dom-material-e6184e4fe7653ac1

A. 28
```

这一行既打断阅读，也把题干和选项的 4-gram 切断——1,003 条低覆盖里的大多数就是这么来的。现在行测的材料按首个引用它的题排序为 `材料 1…N`，直接插在题组前，题干里不再出现内部哈希；申论保留材料前置，只把内部 ID 换成 `材料 N`。

修复后低覆盖降到 242，且**正文零改动**（字符多重集逐卷比对，1206/1206 通过）。

### 2. 319 题缺「考点 / 来源」（74 卷）

表现：

```text
源 explanationHtml:  参考答案说明…… 考点：提出对策类 来源：2016年国家公务员考试申论题（副省级）…（另有解析视频入口说明）
MD 解析区（修复前）:  **解析状态：unknown（来源未提供）**
```

「参考答案说明」在 MD 里本来就有（在答案区），丢的是 **考点** 与 **来源** 两行，以及「本题只提供解析视频、无文字解析」这一事实。集中在 2016–2018 的国考与部分省考申论——早期采集批次的字段映射没有把这段拆出来。

修复直接从 `document.json` 取原文，不重新访问题库：

```markdown
**解析**

**考点**：提出对策类

**来源**：2016年国家公考《申论》题（副省级）

> 粉笔申论页面对本题只提供「解析视频」入口，该入口是会员推广位，页面无视频地址与文字解析。
```

复核：`expl_miss` 从 319 降到 **0**；`<details>` 开闭数不变；除被替换的那一行外没有删除任何正文。渲染器 `src/render.mjs` 同步加了 `explanationFragment()`，后续新采集的卷不会再出现同样问题。

## 2026-10-26 / 27：图片公式转写

早期卷（2008–2015 为主）的题干、选项、解析里大量内容以图片形式存在：粉笔把公式、算式、单位渲染成 `<img>`，采集时按原样存成了 PNG。读者在本地看到的就成了「题干文字却是图」。本轮把它们逐张读出来写成文本。

### 做法

转写不是让模型看图猜，而是**双盲两遍 + 第三遍仲裁**：

1. **A、B 两遍独立转写**同一张图，互不可见。分片按 sha 切、每片约 30–120 张，行测 245 片 × 2 遍。
2. **严格归一化比对**：去空白、全角转半角、`− — –` 统一、`* → ×`、`... → …`、`^+ → +`。一致才落盘（含置信度 `high`）。
3. **宽松归约比对**：A/B 只是写法不同（`＞` vs `大于`、`ab/c` vs `a×b/c`）时，按「前导等号 → 符号数 → 中文措辞 → 长度」规则取信息更全的一方。
4. **第三遍看图仲裁**：仍不一致的分歧，再派一个 agent 亲自看图逐字符核对，判 `a` / `b` / `neither`，或判为图形保留原图。

替换时做了转义：`<`→`＜`、`>`→`＞`、`|`→`｜`、反引号→`'`、去换行，避免把数学内容写坏 Markdown 结构。

### 结果

| 范围 | 转写处数 | 处理 |
| --- | ---: | --- |
| 解析区中图公式（245 片 × 2 遍） | 58,773 | 本轮，A/B 双盲 + 仲裁 |
| 题干 / 选项公式小图 | 929 | 前序批次 |
| 题干区 / 整题截图 | 72 | 前序批次 |
| 题干表格图转 Markdown 表 | 68 处 | 见下节 |
| 仍保留为图片 | 19,493 处引用 / 19,026 张唯一图 | 见下 |

复核：`polish_markdown.py` 二次运行报 `unchanged`；`cloud_quality.py` 报缺图 **0**、图片解码错误 **0**、硬错误 **0**。

**关于原图**：转写后正文不再引用这些 PNG，但 `assets-fenbi-*/` 目录里的原图**全部保留**（共 113,278 张，其中 94,005 张已无引用）。理由是转写结果需要可回溯核对——任何一处公式有疑问，都能按 sha256 找回原图。孤儿图不参与渲染，不影响阅读。

### 题干表格图转 Markdown 表格

公式图是「一行文字」，表格是「一块结构」，替换流程不同：一图换一行文本能直接套用，表格必须换成多行表块。

1. **离线筛候选**：对正文仍在引用的 19,050 张图算三个特征——横竖长直线条数（墨迹连续段 ≥ 55% 宽/高）、格线围成格子的填充率、以及图所在位置是否为题干区。筛出 368 张候选，抽样准确率约五成，其余是折叠盒、三视图这类真图形。
2. **双盲判图 + 转写**：每 12 张拼一张网格图，A/B 各 8 个 agent 独立判断「表格 / 图形」，判为表格的当场转成 Markdown 表。
3. **一致性比对**：严格归一化后（对齐记号、破折号、全角半角、空格）一致才采用，得 65 张。
4. **第三遍仲裁**：剩 3 处分歧（列结构、一个西里尔字母 `Д`、一处「表还是图」判断相反）逐张看原图裁定，采纳 2 张表、1 张保留图形。

| 判定 | 数量 |
| --- | ---: |
| 双盲一致 · 表格 | 65 |
| 仲裁补入 · 表格 | 2 |
| 双盲一致 · 图形（保留） | 300 |
| 仲裁判为图形（保留） | 1 |

写入按块级替换：只有「图片独占一行」的位置才换（这 68 处全部满足）；混在选项行里的图保持原样，避免把表格塞进列表项。替换后 `polish_markdown.py` 重排了空行，表格块列数逐块校验 **0 处不一致**；题目总数 91,111 不变，图片引用 19,561 → 19,493。

### 仍然保留图片的四类

不是没做，是**转写会失真**：

1. **真图形**：三视图、折叠盒、钟面、几何图、数独格、地图、流程图、气象符号。这些本来就是图，转成一行文字反而丢信息。
2. **字符对照题**：江苏「知觉速度与准确性」一类的符号题（`∮ ♂ ♀ ≋` 之类）。同一份卷的「图例」与被考选项必须用**同一套**符号，两次转写很难保证字符级一致，保留原图更可靠。
3. **表格图**：题干里的小表格（九宫格数字推理、年份指标表等）已在 2026-10-27 转为 Markdown 表格，见上节。**资料分析的统计材料表**（1,196 张）、**解析区里的表格**（1,334 张）仍是图片：它们体量大、结构复杂（多层表头、脚注、柱线混排），逐张转写还没做。
4. **无法辨认的乱码图**：原图本身就是 `⊃∪∪⊥∩⚙⊗⊙` 一类的异常渲染，粉笔页面源头即如此。

```bash
python3 tools/audit_fidelity.py --manifest catalog/manifest.jsonl --work <采集工作区>
```

输出逐卷 JSON（题数、异常分桶、图片计数），可再聚合成上表。
