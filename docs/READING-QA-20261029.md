## 3. 两个容易误判的实际例子

### 江苏 2024 C 类第 110 题

文件的题干为「驳岸」定义判断，但四个选项实际为：

- A：征集占位长句（含「正确答案默认设置为 B 项」）；
- B/C/D：仅为「缺失」占位；
- 答案区又写「题目缺失，正在征集，暂以 B 项代替」。

因此**不能只检查 B/C/D 三个简短占位，也不能将答案 B 当成真实参考答案**。这一题在质量状态中应是「缺四个选项，答案未认证」，即使折叠块和题号都齐全。

### 青海 2020 B 类第 28 题

正本和佐证版第 28 题都是「家庭监管……的情况下」的逻辑填空，选项 A 为**正常词语「缺失」**，其他选项为「薄弱 / 不力 / 缺乏」，答案 A，解析说明搭配「家庭监管缺失」。所以它**不是选项空白**；此前仅按「缺失」匹配的自动统计会产生假阳性。

**同类误报还出现在**[国考 2026 行测副省级第 104 题](../国考/2026/行测-副省级.md)的「视野缺失；冰川运动」，以及[北京 2023 行测第 103 题](../省考/北京/2023/行测-统考.md)的「特定 DNA 序列的缺失情况」。这些都是题面正常语义，不是占位。

该佐证版 frontmatter 另明示 `从属佐证版: true`、`正本文件: "行测-B类.md"`、实有 122 题且第 108–122 题对应正本第 116–130 题。因此**证据是补充关系，不可按同序题号强行覆盖正本空缺**。

## 4. 链接、标题和图片的阅读规则

1. **整卷直连**：使用上表真实 Markdown 相对路径。根目录 [完整试卷索引](../catalog/INDEX.md) 已按年份和卷型生成直达文件链接；索引是自动生成件，**不要手工修改它来更新统计**。
2. **题号链接**：新式 `### 第 N 题` 与旧式 `## 第 N 题 <sub>qid…</sub>` 的 GitHub URL fragment 可能不同。最稳妥的是打开整卷后点击 GitHub 实际的题头锚点，不把 `#第-N-题` 写成通用保证。
3. **答案呈现**：折叠区域必须核实存在**实质内容**；`unknown`、`未收录`、免责声明与默认答案都应判为未补。R7 申论还会用 `r7-reference-N` 和自由格式参考作答。
4. **图片呈现**：新源卷的 `assets-fenbi-*/...` 与旧源卷的 `../../../图片/...` 都是本地相对路径；旧源使用 HTML `<img>`，仅数 Markdown `![]` 会错把图片当零。路径存在并不自动证明图与题目相匹配。
5. **页面大小**：130–135 道行测整卷可能是数百 KB 的长文档。直达文件有效，但页面一次加载、浏览器内搜索体验与断网表现取决于客户端；本次未做浏览器性能压测。

## 5. 修复优先级与后续复验

优先级顺序：**真实缺题/缺选项 → 缺失参考答案与给定材料 → 断图或错图 → 题序与卷型身份 → 视觉排版**。每修一卷应记录：文件路径、Git SHA、原题号与来源题号、题干/选项/答案/图片指纹、摘要及校验结果。

本地可复核结构与图片引用：

```bash
python3 tools/cloud_quality.py --check --verify-images
```

如要声称真正通过完整阅读验收，还需另行打开实际页面、核首/中/末题图文和答案区域，并填写 L3 结果（见 [整卷验收制度](../reports/ACCEPTANCE-PROTOCOL-20261027.md)）。按类别汇总的缺口与统计口径见 [最新缺口总账](GAP-STATUS.md)。
