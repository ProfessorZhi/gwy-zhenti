# gwy-zhenti 统一归档与质量标准

> 生效口径：2026-10-27。**本文件是现行试卷归档与验收标准**；`docs/SCHEMA.md` 定义具体 Markdown 结构，`docs/QUALITY.md`、各期审计报告记录发现与历史数据。历史报告中更严格或过时的“完成”定义，不覆盖本标准。

## 一句话原则

**排版整齐、没有明显错误、图文完整；粉笔真实考试卷中实际能取得的题目、材料、选项、参考答案和解析，按来源忠实归档。**

目标是“考生打开就能正常阅读与做题，AI 能准确定位内容”，不是把所有试卷都认证为政府发布的官方纸质原卷。

- **真实考试及其标明性质的回忆版都可以归档**；保留`真题性质`与`来源`，不把网友回忆版伪装成官方原件。模考、预测题、改写训练题不混入真题目录。
- **粉笔有的内容必须尽量完整收录**，包括可取得的题目、选项、共同材料、给定资料、答案、范文、解析正文以及实际可用的题图和表图。
- **粉笔本来没有的内容不编造**：明确标注“来源未提供/题位占位/无法取得”，已取得部分仍可归档，但不能宣称整卷完整。
- **不强制每道题都有独立文字解析**。若来源只给参考答案、范文、考点或视频入口，就保留真实存在的内容和状态；“有视频入口”不等于已取得视频文件。
- **不以“全卷经人工逐字通读”或“找到官方扫描原件”作为一般归档前提**；机器全量验收加针对性人工抽查即可入库，异常卷/题继续专项核实。
- 遵守来源材料适用的使用与公开分发许可；第三方页面可访问、用户拥有学习账号或仓库为 public，本身都不能代替全文及图片的转载授权。

## 合格归档的四项检查

### 1. 排版整齐且可用

- 文件名、卷首信息、地区/年份/科目/卷型、题目层级与章节清晰；`frontmatter` 可解析，`manifest` 与正文一致。
- 行测按照来源题序展示题干、A/B/C/D 等实际选项、共用材料；申论材料完整呈现、作答要求和字数/分值不丢。
- 答案/解析优先紧跟各题并默认折叠，避免做题时提前泄露；旧来源的其他可解析版式允许按批改造，不因单纯版式不同直接判“缺答案”。
- Markdown 表格、图片、公式、特殊字符在 GitHub 预览里能正常阅读；不为追求“全部文字化”强转图形、统计图或低置信度公式。

### 2. 看不出明显内容错误

以下情况必须定位并修复，不能以“机器检查通过”掩盖：

- 题干、选项、答案或解析串题/错题，题号对不上，题目被截断，A/B/C 类、场次或年份被错认；跨卷共用题须有明确来源证据。
- 申论题干写“给定资料 N”却链接到不相干材料；如果内部重新编号，必须有可信的原编号对应关系。
- 图像丢失、断链、错位、无法解码或明显模糊；表格转换错列、掉行、漏数字，公式转写改变符号或含义。
- 渲染或清洗吞字（尤其 `<`、下标、特殊符号）、出现大量乱码/重叠标记，或者明知源有答案解析却在库内误写 `unknown`。

### 3. 来源有的内容不遗漏

- 逐卷以已取得、能合法使用的**固定粉笔来源版本**作为对账基线；比对题号/题干/选项、材料、参考答案、解析、图片引用的对应情况。
- **源有、本库漏了 = 必修错误**。能从来源取得而未归档的真实题目/材料/答案/解析不得标“完整”。
- **源本来没有/当前无法访问 = 来源缺项**。保留题位或现有题文，记录缺的是题、答案还是解析，不凭空补题，不用“默认 A”充数，也不让缺项隐藏在题号连续或 `<details>` 折叠块计数里。
- 多个来源的答案不同时保留各自出处和待核标记；不因投票、同年同省或答案看着合理就认定正确。
- 图片可继续保留本地相对路径；转换为文本/表格时保留可回溯的原图，不要求所有图片都转换。

### 4. 可追溯、可检查

- 每卷至少记录地区、年份、科目、卷型、来源及可用的`源试卷ID`、`真题性质`、`校验状态`；没有来源 ID 的其他合法来源用名称/URL/题本证据说明，不杜撰 ID。
- 保存相应文件 SHA、题数、实际题位/答案状态、引用图片存在性及重要差异；报告必须区分**验证过**与**只是未发现错误**。
- 批次执行结构/断图/答案绑定与 Markdown 检查，并抽查不同卷型、年份、图表题、申论材料；已触发的异常必须针对性复核，不要求对所有正常卷逐题人工通读。

## 统一的收录和质量状态

| 状态 | 何时使用 | 是否允许归档 |
| --- | --- | --- |
| **已归档 · 来源范围完整** | 来源可得到的真实题目、材料、答案和解析已忠实收录；排版可读、无已知严重错误、图片正常 | 是 |
| **已归档 · 来源原缺** | 题本为真题或明确标为回忆版，但来源本身缺部分题/答/解；本库如实留位并标记 | 是，**但不计作“整卷内容完整”** |
| **需修复 · 本库缺损** | 来源已有内容，而本库漏采、错位、缺图、错答案或严重排版错误 | 不得标“合格完整”；修复后重新验收 |
| **待核 · 身份或使用权限不明** | 无法确认是否同卷、是否真题，或无法确认该内容允许当前存储/分发 | 保留核验记录；不得冒充合格正式归档 |

**是否在 `main`、是否经过人工通读、是否为官方原件**分别记录，不与上表状态混成一个数字。已经提交到 `main` 的旧文件如仍写“候选，未正式入库”，按证据逐批清理字段，不为改变标签而倒推其内容已验真。

## 统一的进度与缺口口径

报告至少分别列出：

1. **卷目录匹配**：粉笔目录有多少真实考试卷、本库匹配多少；精确来源 ID 和仅按规范名回退必须分开。
2. **来源可得内容归档**：来源实际提供的题干/选项/材料/答案/文字解析中，有多少已经写入本库；视频入口与独立文字解析分开。
3. **来源本身缺项**：粉笔页面的占位题、无答案、无解析、会员不可见等另列，不算本库漏采，也不计为整卷内容完整。
4. **本库真实错误**：来源存在但本库缺失、错误链接、解析误标、错卷、材料编号错配和确认损坏的图文。
5. **验证覆盖**：机器对源逐项核对、人工异常复核、人工整卷签收分别计数，不能把`0`条错误等同于`100%`逐字验真。

**不同维度不相加**。一题“题干缺失”可能同时导致“答案缺失”，重复计数只能用于不同维度指标，不能汇总称为新增缺题。以当前文件和固定来源的可复现结果为准；旧阶段快照不再作为现行缺口。

## 已有特殊口径继续有效

- **`卷型: 统考` 是内部兜底类别**，与真实 A/B/C、县乡、行政执法等分卷并存时不自动多算一份真实原卷。
- **没有 `### 第 N 题` 不等于申论缺题**；旧格式可能以“问题一/作答要求”表达，需按真实题文判别。
- **历史上游截断**与**现仍缺失**是两个字段。过去已经补齐的材料尾部不再计作当前缺口，但没有原卷证据时不得推定整卷所有材料必然完整。
- 同卷异版、不同地区联考共享题、不同卷型及上下半年考试必须依据题文/场次/来源区分，不可仅凭文件名或 `sourceId` 数量推断质量。

---

**最终验收目标：粉笔实际有的真题内容全部忠实归档，排版整齐、图文完整、无明显错误；来源没有的诚实标明，既不编造，也不让它阻塞已经可用的其他真题。**
