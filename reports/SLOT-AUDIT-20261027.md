## 二、口径与方法

### 2.1 槽位

`(地区, 年份, 科目, norm_pt(卷型))`。`norm_pt()` 来自 `tools/coverage_stats.py`：去掉尾部长数字后缀、统一全半角冒号、甲级/乙级、A卷→A类、去掉尾部“卷”。行测目录没有独立卷型字段，卷型从标题解析（副省级/地市级/行政执法/A/B/C/县级/乡镇/选调生/上半年/下半年/单考区/应届/社招/春季等）；申论目录用 `variant`（a/b/c/county/township/xingzheng/liankao/unknown）。

### 2.2 身份判定优先级

1. **`源试卷ID` 严格一致**：目录条目与本地 frontmatter 的 ID 相同，即同一张卷。
2. **frontmatter 声明**：`从属佐证版: true` + `正本文件`、`重复来源`、`同卷备份`、`合并建议`、`互补版本`、`互补说明`。这是仓库内最直接的重复/互补证据。
3. **题号序列 + 题量**：同槽文件的 `### 第 N 题` 序列是否一致、是否一方为另一方的前缀/子集。
4. **材料 4-gram 覆盖率**：NFKC 归一化、去除全部空白与 `<details>` 答案块后，取 4-gram 集合；`covA=|A∩B|/|A|`、`covB=|A∩B|/|B|`。`covMin` 低只能说明“不是逐字同源”，不能单独证明不同卷；山东 2025 C 卷/类即为反例（材料被改写，覆盖率仅 0.095，但四题题干与分值逐题一致）。

### 2.3 判定类别

- `duplicate`：同一张卷的重复采集、残件、互补件、命名变体。
- `distinct`：同槽不同卷（统考 vs 分类卷、上半年 vs 下半年、不同职位卷、不同考试）。
- `unclear`：证据不足。本次为 0。
- `same-content-different-id`：两份都有 sourceId、ID 不同、但 `covMin>0.95`。本次为 0（23 对双 ID 文件中最高 `covMin` 仅 0.318，广东 2013 行测一/三）。
