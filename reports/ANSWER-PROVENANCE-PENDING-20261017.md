## 2. 已证实的元数据缺陷（1 项）

### 2.1 `省考/黑龙江/2019/行测-边境县.md` — frontmatter 陈旧，与正文和凭据矛盾

现有 frontmatter：

```
答案来源: "缺（两源均无此卷答案）"
校验状态: "仅源抽取（上岸通）；答案/解析源缺；未人工通读"
```

**证据（三重一致）**：

1. 该文件 120 个答案块**逐题**写有
   `**来源**：用户提供《2019年黑龙江边境县…《行测》真题答案及解析.pdf》，第N题；
   资料性质为机构/个人整理参考解析，原文件标记「来源：F」（未明确机构全称），
   **不是官方公布答案**。源文件SHA-256：fdb936bd09f0714dce5b306a55d275987deba72242460ade4062ea68d880fab4`。
2. `reports/FULL-REPAIR-APTITUDE-ANSWERS-20261015.json` 中该卷记录
   `source_sha256 = fdb936bd…`、`existing_agree = 0`、`missing = [1..120]`、`added` 120 条。
3. `reports/full-repair-20261015/receipts-003.jsonl` 记录同一路径的 `modified` 操作，
   插入的正是这些答案块。

即：**答案来源是明确且可核的，frontmatter 的两行是补录前写下的陈旧描述。**

### 2.2 修复候选（**未应用**）

```diff
-答案来源: "缺（两源均无此卷答案）"
-校验状态: "仅源抽取（上岸通）；答案/解析源缺；未人工通读"
+答案来源: "用户提供《2019年黑龙江边境县（市、区）急需紧缺专业岗公务员考试《行测》真题答案及解析.pdf》（sha256=fdb936bd09f0714dce5b306a55d275987deba72242460ade4062ea68d880fab4）；机构/个人整理参考解析，原文件标记「来源：F」（未明确机构全称），非官方公布答案；逐题来源见各答案块「来源」行"
+校验状态: "仅源抽取（上岸通）；答案/解析由同卷用户提供解析 PDF 补齐 120 题，凭据 reports/FULL-REPAIR-APTITUDE-ANSWERS-20261015.json；未人工通读"
```

**为什么没有直接应用**：`tools/full_repair_receipts_20261015.py::verify()` 对每条路径只允许
**一条** receipt，并要求当前字节等于该 receipt 的 `after_sha256`（实测该卷当前 sha256
`765635610b37a603dda3d5bfe7ab42d35578c1c089eda8dbf64d7853d06c73f5` 与其 receipt 完全一致）。
改了字节而不追加新 receipt，`verify()` 会以 `Current postimage mismatch` 失败。
重新生成 receipt 是 `--capture` 的全量动作，会影响其他 lane 正在使用的凭据链，
**不属于本 lane 的安全范围**。

落地方式（任一）：

- 由持有 full-repair 凭据链的 lane 应用上列 diff 并**追加一条 receipt**（before/after sha256 +
  operations），随后 `python tools/full_repair_receipts_20261015.py` 应仍通过；
- 或在下一次 `--capture` 时一并纳入。

## 3. 待核裁定（1 项，不提供改法）

### 3.1 `省考/辽宁/2017/行测-公安.md` — 「官方」称谓与自身来源别名不一致

```
来源: ["huatu-zhenti", "huatu-zhenti-ans"]
来源明细: "…答案 同批官方《行政职业能力测验解析》PDF(sha256=81449dd3…)…"
校验状态: "…答案取自官方解析 PDF…"
```

**已能证明的**：该卷声明的来源别名是 `huatu-*`（华图），而正文把同一份 PDF 称作「官方」；
该 PDF 的 sha256 `81449dd308fed59f6fb92bd23f4b02647c6124b6788913fe16f4f83226dfffbc`
在 `reports/`、`docs/`、`catalog/` 中**没有任何留存凭据**；本机也没有该 PDF 文件。

**尚不能证明的**：该 PDF 究竟由谁发布。因此**不做修改、不擅自降级**——
把可能真实的「官方」抹掉，和把机构写成官方，是同一种失真。
按 `QUALITY.md` 第 42 行「来源页面写着官方解析不自动等同于政府正式发布」，
该项应标为**待核**，直到取得原件。

判定标准（取得原件后照此裁定）：

- 版权页/页眉署名省级人社部门或考试院 → 保留「官方」并补引用页码；
- 署名华图或其它机构 → 删去「官方」，改为机构名；
- 无署名 → 记为「发布方不明」，不得使用「官方」。
