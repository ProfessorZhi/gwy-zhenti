- 替换后 `tools/audit_images.py`：图片引用 65,406 处，**断链 0**；`refresh_manifest` 刷新 528 行 sha256；测试套件通过（3 项 `bs4` 导入错误为本地缺依赖，CI 会装）。
- 同一内容图在不同试卷、选项、解析里重复出现，按 sha256 全局替换，因此替换处数远大于图片数。
- 图片文件**一张未删**，只去掉正文引用；映射表可回溯、可还原。

## 方法

1. **建目标集**：扫描全部 MD 的图片引用，取宽度 ≤60px 的位图，按 sha256 去重。
2. **双盲两遍**：A、B 两组 agent 各自只看图、不看对方结果，按同一套书写规范转写。
3. **规范化比对**：忽略空白、全角/半角标点、`^(x)` 与 `^x`、单层冗余括号（`(3√3)/7` 与 `3√3/7`），其余须逐字符相同。
4. **仅一致者替换**：不一致一律保留原图；图形、表格、数阵、照片一律保留。
5. **并行**：第二波按 sha 切成 30 片，30 个 agent 同时跑 A 遍，完成一片即发对应的 B 遍，全程约 75 分钟。

## 书写规范

| 对象 | 写法 |
|---|---|
| 分数 | `分子/分母`，复合分子加括号 `(a+b)/c` |
| 幂、根 | `x^2`、`√3`、`5√2 cm` |
| 上下标 | 下标 `_`、上标 `^`，同时出现写 `A_8^2` |
| 运算符 | `× ÷ - + ≥ ≤ ≠ ≈ % ° →`，两侧不加空格 |
| 数字 | 原样，数字与单位间一个空格 |

## 映射表

`reports/formula-transcription-20261023.jsonl`，4,403 行，每行一张图：

| 字段 | 含义 |
|---|---|
| `sha` | 图片内容 sha256（assets 目录下文件名即该值） |
| `text` | 采用的转写文本；figure 为空串 |
| `kind` | 逐图类型：fraction / number / symbol / expression / figure（两遍 agent 用词不完全统一，figure 为保留原图项） |
| `confidence` | A 遍自评 high / medium / low |
| `match` | exact（逐字一致）/ normalized（规范化后一致）/ figure（双方都判为图形） |

## 分歧样本

| 内容 sha 前缀 | A 遍 | B 遍 |
|---|---|---|
| `003de4b4` | `-1/2` | `1/2` |
| `ec98e8df` | `56` | `5^6` |
| `bd197627` | `⁵√3` | `3^(1/5)` |
| `d8428719` | `26√33` | `√33` |
| `1c4efea0` | （判为图形） | `n∞↓→n∑→` |

正负号、上下标、根式层级、符号串是最容易读错的四类；这类一律不替换。
