# 小图公式转写（第一波）2026-10-23

## 结论

- 题干、选项、解析里的行内公式长期以位图形式存在（宽 ≤60px，源站 TeX 已丢失），正文读起来是“图文夹杂”。
- 本轮把 **334 张唯一小图**（169 道“题干几乎全是图”的题目，541 处引用）做双盲转写。
- **314 张两遍一致**：其中 273 张替换为纯文本（覆盖 **2,829 处**引用、**442** 份试卷），41 张判定为图形/表格（figure）保持原样。
- **20 张两遍读数不一致**，按规则保留图片，不猜。
- 替换后 `tools/audit_images.py`：图片引用 84,029 处，**断链 0**。测试套件通过。
- 全量目标 4,622 张唯一小图（22,642 处引用），第二波 4,365 张正在按 sha 分片并行转写。

## 方法

1. **建目标集**：扫描全部 MD 的图片引用，取宽度 ≤60px 的位图，按 sha256 去重 —— 4,622 张唯一内容。
2. **双盲两遍**：A、B 两组 agent 各自只看图、不看对方结果，按同一套书写规范转写（分数 `分子/分母`、幂 `x^2`、根号 `√3`、运算符不加空格等）。
3. **规范化比对**：忽略空白差异、`^(x)` 与 `^x`、单层冗余括号（如 `(3√3)/7` 与 `3√3/7`）后仍须逐字符相同。
4. **仅一致者替换**：不一致的保留原图；图形、表格、数阵、照片一律保留。
5. **按内容替换**：同一 sha 的图在不同试卷、选项、解析里重复出现，一律同步替换（因此替换处数 2,829 远大于第一波的 541 处引用）。

图片文件本身**未删除**，仅去掉正文引用；映射表可用于回溯与还原。

## 映射表

`reports/formula-transcription-20261023.jsonl`，每行一张图：

| 字段 | 含义 |
|---|---|
| `sha` | 图片内容 sha256 |
| `text` | 采用（或 A 遍给出）的转写文本；figure 为空串 |
| `kind` | fraction / number / symbol / expression / figure |
| `confidence` | high / medium / low（A 遍置信度） |
| `match` | exact（逐字一致）/ normalized（规范化后一致）/ figure（双方都判为图形） |
| `applied` | 是否已写入正文 |
| `paths` | 该内容的现存文件路径 |
