# 整卷验收口径：把「0 / 1,850 已人工验收」变成一个可执行的三层制度（2026-10-27）

`catalog/manifest.jsonl` 里 1,850 卷全部是 `whole_paper_acceptance: not_certified_by_this_audit`。
这个字段现在既不能被读成「1,850 卷都可用」，也不能被读成「1,850 卷都不可用」——
它只说明**没有人逐字读过**。本文件定义三层验收，让「验收到哪一步」变成逐卷可查的状态，
而不是一个全库否定的字符串。

## 三层口径

| 层 | 验什么 | 覆盖面 | 手段 | 判据 |
| --- | --- | --- | --- | --- |
| **L1 结构自洽** | 卷内题位、答案块、材料编号、图片引用、声明题数是否自相矛盾 | **全量 1,850 卷** | 纯机器、可复现 | 断言全过才算 L1 |
| **L2 来源一致** | 仓库正文与采集到的原始 `document.json` 是否逐题对得上 | 有采集缓存的卷全量；无缓存的卷随 L3 抽样补采 | `tools/audit_fidelity.py`（4-gram 覆盖率）+ 抽样人工归因 | 覆盖率 ≥0.9 或低覆盖已归因 |
| **L3 人工通读** | 能不能拿这份卷直接做题：题面、选项、作答要求、答案、解析、材料、图片是否都读得通 | **分层抽样**，按样本量推算全库 | 人读 + 逐卷断言清单 | 逐卷记 pass/fail 与缺陷类型 |

三层不是替代关系：L1 通过不代表内容对（黑龙江 2019 边境县行测就曾经「结构全过、答案统计全错」），
L3 抽样通过也不代表 L1 全量通过。**对外只能说清「哪一层、覆盖多少」。**

## L1：结构自洽（全量，已跑出第一版数字）

断言清单（全部可脚本化，无人工判断）：

1. frontmatter 必填字段齐全（`考试/地区/年份/科目/来源`）；
2. `question_anchors == declared_questions`（题位完整、无缺口）；
3. `missing_original_numbers` 为空（原题号缺号已登记）；
4. `current_truncated_questions` 为 0（现在不存在截断题）；
5. `has_answer_content` 为真，或该卷已在清单 A 明确登记缺答案；
6. `issues` 为空，**或每条 issue 都已在归因表里登记**（答案数量与题量不一致、未检测到参考答案等）；
7. 申论卷 `### 材料 N` 编号从 1 连续到 N；
8. 每个图片引用都能解析到实际文件。

## L2：来源一致（按缓存覆盖，已全量跑完）

`tools/audit_fidelity.py` 逐题比对 MD 与本地 `document.json`：题干、选项、答案、解析、图片。
它回答的是「仓库有没有在和原始采集的搬运过程中失真」，不回答「原始采集本身可不可信」。

- 有缓存的卷：全量跑，覆盖率 <0.9 的逐条归因（源被截断 / 申论答案落在别处 / 真缺失）；
- 无缓存的卷：随 L3 抽样补采后一并跑，不单独为覆盖率回采全库。

注意：覆盖率是**线索**不是判决。申论材料常被截断、M1／M2 互换，覆盖低不代表仓库错了。

### 低覆盖 2,848 条的归因（不是缺失）

低覆盖 = 题干 593 条 + 解析 2,255 条，覆盖率中位数 0.86–0.875。
判据不用覆盖率阈值，用**源文本里最长的一段连续未覆盖片段**：页面杂项、表格重排、
公式位图转写只会造成短碎片，整段丢失才会留下长断档。

| 最长未覆盖片段 | 条数 | 定性 |
| --- | ---: | --- |
| 无 ≥15 字断档 | 2,527 | 标点/符号归一化、选项字母位置差异，逐字都在 |
| 15–19 字 | 43 | 页面杂项（见下） |
| 20–39 字 | 278 | 页面杂项（见下） |
| **≥40 字** | **0** | 本轮修复前是 6 条，见「答题演示」段 |

321 条有 ≥15 字断档的记录逐个看过片段原文：

- **290 条是纯页面杂项**：「…字」字数提示、「解析视频 粉笔申论会员 173xxxxx 人已开通」、
  「考点…类 来源 20xx年… 网友回忆版」这类卡片元信息。仓库惯例是不转写这些版式杂项。
- **31 条是表格重排与公式符号剥离**：源端表格在 `nz()` 归一化后变成「为江苏甘肃广东上海浙江北京四川」
  这种无分隔拼接，库内是带公式的逐省算式；抽查国考 2023 副省级第 123 题、江苏 2018 A 类第 60 题，
  正文逐字都在，属归一化差异。

另外 42 条题干覆盖率 <0.5（最低 0.000）也没留下 ≥15 字断档：这些是**数字推理/几何题**，
源端公式是位图（`<img flag="tex" src="…/formulas?latex=…">`），库内已按
[`FORMULA-TRANSCRIPTION-20261023.md`](FORMULA-TRANSCRIPTION-20261023.md) 的映射转成文本，
所以字面不同、内容等价（上海 2021 A 类第 61 题、江苏 2020 A 类第 47 题等）。

### 36 卷身份不符：`源试卷ID` 在这批件上不可信

身份预检（地区/年份/科目）挡下 36 卷，`源试卷ID` 全部落在 43–275，年份全部是 2008–2012：
这批遗留件把**清单序号**当成了 `源试卷ID`，于是撞上别的卷的真实 ID（34 卷撞到申论缓存、

既不算通过也不算失败——它们的 L2 结论目前是「无法比对」，要等真实 ID 补上。

## L3：人工通读（分层抽样）

### 分层变量

用 manifest 已有字段分层，层内随机抽：

1. `area`（国考 / 重点省 / 非重点省）——政策重点直接影响抽查强度；
2. `year`（2015 前 / 2016–2020 / 2021 以后）——早年卷第三方源比例高；
3. `subject`（行测 / 申论）——两类缺陷形态不同；
4. `source_validation`（候选 / 机器校验）。

### 样本量

按简单随机比例估计（95% 置信、有限总体 N=1,850）：

| 允许误差 | 需要样本 | 含义 |
| --- | ---: | --- |
| ±10% | **92 卷** | 第一轮建议规模；约 5% 的全库 |
| ±7% | 187 卷 | 第二轮 |
| ±5% | 319 卷 | 「可以对外说合格率」的最低门槛 |

**现在还不能说「合格率是 X%」**——L3 一卷都还没抽。先前报告里任何「覆盖率」数字都只能读成
「有多少文件存在且结构自洽」，不能读成「有多少卷能直接做题」。

### 每卷人工断言清单

抽中的卷按同一张清单逐条判，结果只记 pass / fail + 缺陷类型：

1. 卷面声明题数与实际题数一致，题号连续；
2. 每题题干完整（不是「正在全力以赴征集」类占位），选项 ≥4（行测）或作答要求完整（申论）；
3. 每题答案不是免责声明，解析不是纯图；
4. 申论每道题的「给定资料 N」都能在材料里找到对应那一则，且内容与题干指向一致；
5. 图片与所在题目对应（不是张冠李戴的邻题配图）；
6. `**来源**：… 第 N 题` 指向的兄弟卷确实有同题且同答案。

### 记录方式

抽中的卷在 manifest 里补两个字段：`acceptance_level`（`l1` / `l1+l2` / `l1+l2+l3`）与
`acceptance_sample`（批次号 + 结论 pass/fail + 缺陷类型）。没被抽中的卷保持 `l1`，
**不写「已验收」**。
