## 3. 表头语义：23 张把数据行当表头（含归因与补丁）

### 3.1 缺陷本质

GFM 表格**必须**有表头行。数阵题（九宫格、区间表、多块数组）本来没有列名，转写时把
第一个数据行放在了表头位置，GitHub 渲染时整行加粗、分隔线画在数据行下方，读者会把它
当列名。**内容没错，是呈现语义错位。**

### 3.2 检测规则（缺一不可，否则全是误报）

| 误报类型 | 反例 | 判据 |
|---|---|---|
| 时间轴 | `2018\|2019\|2020` | 行级年份域 1900–2100 + 单调，才算表头 |
| 序号轴 | `1\|2\|3\|4\|5\|6` 压在文字行上 | 数字是否继续数到正文里 |
| 空角格 | `\| \| 45元 \| 75元 \|` | 表头常留空角格 |
| 中文后缀 | `2次逻辑` | 单位用**闭集白名单**，不用开放正则 |
| 单字母 | `A\|B\|C\|D` vs `a\|4\|8\|m` | 同行有没有真数字 |

调参过程中这五类误报分别把数字抬到 68 → 27 → 24，最终稳定在 **23**，与 Q6 独立得出的
23 张吻合。

### 3.5 安全表示方案（适配 GitHub 语义表）

**主方案（补丁采用）：空表头 + 原表头降级为首数据行**

```markdown
| | | |
| ---: | ---: | ---: |
| 7 | ? | 20 |
| 6 | 22 | 30 |
| 17 | 21 | 40 |
```

GFM 允许表头单元格为空，渲染为一个**空表头条**，数值落在 `<td>`。不新增任何列名、
不改任何数字、可逐字节还原。

**备选（仅记录，不自动应用）**：`<table><tbody>` 无 `<thead>` 是最忠实的编码，但偏离本库
纯 Markdown 约定，且会让现有审计工具失效，因此只在「空表头仍然读起来别扭」的极少数表上
人工考虑。工具提供 `--alt-html` 打印样张。

## 5. 符号与公式：按「卷 × 单元」分桶

### 5.1 口径

- 只在**正文散文**里扫描：先剥掉 `<details>/<summary>/<img>`、Markdown 图片、自动链接，
  再找符号。**代码块与 HTML 标签不算**。
- `大于/小于` 只有**邻近 6 字符内有数字**才算比较运算符，否则是成语（`利大于弊`、`供大于求`）。
- 每个命中都挂一张**原图 SHA**（最近的上方图片）与证据等级；**只挂指针，不判字形**，
  所以 `evidence=IMAGE_ONLY` 时置信上限就是 `medium`。

### 5.2 全库计数（1,850 卷，928 卷有命中，共 102,315 处）

| 类别 | 处数 | 说明 |
|---|---:|---|
| `MATH_SYMBOL` | 37,644 | `÷ √ × ≤ ≥ ≈ ±` 等，多为解析里的正常用法 |
| `FRACTION` | 35,004 | `2/3`、`13/21` 等真分数（已排除 `2024/10` 这类日期） |
| `SUPERSCRIPT` | 10,439 | `3^2` 这种 ASCII 写法，GitHub 不会渲染成上标 |
| `GT_FULLWIDTH` | 5,719 | `＞` |
| `LT_FULLWIDTH` | 4,426 | `＜` |
| `GREEK` | 3,797 | `ρ` 等物理量符号 |
| `WORD_OP` | 2,574 | 数字旁的 `小于/大于` |
| **`LT_RAW`** | **1,367** | 半角 `<` 作比较运算符，**370 卷**（其中 1,294 处在解析区） |
| `GT_RAW` | 944 | 半角 `>` 作比较运算符 |
| `HTML_ENTITY` | 401 | `&lt;` / `&gt;` |

> **与 Q6 的 142 卷 / 286 处对不上，原因已定位**：Q6 只统计「半角 `<` 作比较运算符」的一个
> 更窄子集（其规则未公开）。我这条规则是「剥掉 HTML/Markdown 后，`<` 左右 2 字符内有数字」，
> 得 1,367 处 / 370 卷。**两者分母不同，不可互相引用**；可复现的是本文的口径。
> 中间我还修过一个真 bug：早期正则会漏掉 `23% < x`（`<` 后跟空格）这种**最常见**写法，
> 结果 Q6 点名的 云南2018 案例一开始抓不到。

### 5.3 真正值得修的一类：同一单元混用两种写法（329 个单元）

单看每一处都读得懂，但**同一道题里**同时出现两种符号，读者会怀疑是不是两个不同符号。

已复现 Q6 点名的云南2018 q62：

```text
80 × 0.2 ＜ 4.5 + 50x ＜ 80 × 0.35，解得：23% < x < 47%。
                    ↑ 全角               ↑ 半角
```
