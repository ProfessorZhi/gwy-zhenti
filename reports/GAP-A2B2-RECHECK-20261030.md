## 1. 本次结果与严格口径

本次脚本读取 `catalog/manifest.jsonl` 里的 **1,683 份 Markdown / 90,123 个题目位置**，以当前正文而非旧 report 标签为准。现存 4 份标有 `从属佐证版: true` 的文件，共 132 个题位，仅留为来源交叉证据，不作为新增独立答案债务。**脚本不会修改试卷。**

| 缺口类型 | 本轮有明确证据的数量 | 说明 |
| --- | ---: | --- |
| **A1 · 原题正文仍为粉笔占位** | **280 个题位 / 60 卷** | 与 10-30 的逐卷复核一致，未因本文重算而变化 |
| **A2 · 题干存在但至少一个选项是明确占位** | **6 题位** | 3 题多选项占位可直接机器识别，另 3 题是逐题人工裁定的单个选项缺失 |
| **B2 · 题面存在但参考答案明确未收录** | **7 题位 / 3 卷** | 由卷内声明、`缺参考答案题号` 和题区正文对应确认 |
| **明确缺内容的文件题位（A1∪A2∪B2）** | **293 个互不重叠题位** | `280 + 6 + 7`，去重键为 `path + question_number`；并非全国唯一原题数 |

**统计边界**：上述 293 是目前**保守、可追溯的确认数**，不是“只缺 293 道题”的完整性认证。扫描会漏掉没有占位提示、缺图、来源版本错误、答案字母与真实选项错配、未标记但隐性缺答等质量问题。主件/佐证件按声明去重，也不能等同于跨卷同题全国去重。
