## 二、根因 A：作答要求项被并入答案区（166 题 / 77 份）

### 证据形态

题块在 `### 作答要求` 之后**止于“要求：”**，而要求项本身出现在 `## 答案与解析` 的 `<details>` 块内，与“第一题 + 题干”的复述拼在一起。以 `国考/2016/申论-副省级.md` 为例：

```
## 第 1 题（单一题）
### 给定材料  … 材料1 …
### 作答要求
阅读“给定资料”，概括全国“两会”代表委员们所关注的若干问题，及其所给出的具体建议。
要求：                     ← 题块在此结束，要求项不在题块内
## 第 2 题（综合题）
…
## 答案与解析
<details>
<summary>第 1 题</summary>
…答案…
第一题
阅读“给定资料1”，概括…（15分）
要求：
（1）全面；
（2）准确；
（3）简明；
（4）不超过200字。      ← 要求项在答案区
</details>
```

这正是“**字数要求分离 + 残留模块拼接**”：同一题的要求项被搬进答案块，题干本体反而看不到“不超过多少字”。

### 样例（前 14 条中的代表）

| 文件 | 题 | 题块结尾 |
|---|---:|---|
| `国考/2016/申论-副省级.md` | 5 | …写一篇文章。（35分） 要求： |
| `国考/2016/申论-地市级.md` | 4 | …写一篇文章。（40分） 要求： |
| `国考/2017/申论-副省级.md` | 3 / 5 | …谈谈对这句话的理解。（15分） 要求： / …以“以水为师”为题…（40分） 要求： |
| `国考/2018/申论-副省级.md` | 3 / 4 / 5 | …加以分析。（15分） 要求： 等 |
| `国考/2018/申论-地市级.md` | 3 / 5 | …谈谈你对这句话的理解。（20分） 要求： 等 |
| `国考/2019/申论-地市级.md` | 5 | …写一篇文章。（40分） 要求： |

分布：国考 26 题、省考 140 题。**注意这是位移，不是丢失**——要求项在答案区可见；但题面区的“作答要求”因此不完整。

### 修复前提（本轮未做）

1. 要求项回流到题面 `### 作答要求` 后，答案区的重复题干文本必须同时移除，否则造成新的重复。
2. 答案区文本属既有凭据，`verify_repair_receipts.py` 会逐字校验 `<details>` 块哈希，任何回流都**必须追加新一轮凭据**，不能改写历史行。
3. 需逐份比对来源，区分“源本身未给要求项”与“转录时错位”。

## 三、根因 B：辽宁2017 申论-公安 有答案无题目锚点

```
## 一、注意事项
## 二、给定材料        （材料以行内“材料一：…材料六：”出现）
## 三、作答要求        （题目以行内“问题一：…问题四：”出现）
## 答案与解析          <summary>第 1 题 … 第 4 题（4 个 <details> 块）
```

全卷**没有 `## 第 N 题`、也没有 `## 给定资料 N`**，4 个答案块因此悬空：读者无法从答案定位题目，机器也无法把答案挂到题号上。这是全库唯一一份此类试卷。

## 四、误报与噪声（已剔除，未计入上表）

- `docs/superpowers/plans/2026-10-09-gwy-zhenti-m1-merge.md`、`…-m3-shenlun.md` 是**计划文档**，不是试卷：其“多答案区”“答案无题目”“题号不递增”属文档本身的陈述，不是试卷缺陷。
- 早期规则把“本次共招聘了50×3=150名应届毕业生”之类的**解题文字**误判为过期计数摘要（3 处，浙江2025行测 A/B/C）。收紧规则（要求数字后紧跟“题/收录”）后归零。
- 早期版本用 `^## 第 N 题$` 精确匹配，漏掉了带题型括注的 `## 第 N 题（单一题）`，一度把 688 份申论判成“作答要求无止”，本报告已改为 `^#{2,4} 第 N 题[^\n]*$` 并**只检查 `### 作答要求` 子块本身**。
