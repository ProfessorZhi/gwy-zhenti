## 2. 状态口径

`audit.csv` 的 `status` 使用以下主分类：

| 状态 | 含义 |
|---|---|
| **源侧本来缺失** | 粉笔主源或同卷公开镜像中该题号逐字为“题目正在全力以赴征集/暂缺”；如有第二公开版本，则同号同占位。**表示主源缺失，不表示全网不存在**；华图同卷候选是否另有正文，在 `evidence`/`next_step` 单独标注 |
| **异版不匹配** | 同题干/同考点存在可读版本，但选项集、卷型或题号体系不同，不能按题号移植 |
| **确认可核** | 内容可读且能逐题锚定；用于北京2025 答案映射（不是补题） |
| **同卷候选详情不可读** | 目录题量/模块同卷，但正文在登录/会员墙后，未读到题目 |
| **本地缓存缺失** | 目标卷/题在本地缓存与公开页面均无可读正文（本轮未出现单独使用；多数并入“源侧缺失”） |
| **未查到** | 指定入口范围内未查到该卷/题；不等于全网不存在 |
| **已收录（答案第三方非官方）** | 已入库，但答案来源不是官方/独立可核 |
| **无缺口** | 槽位与局部缺口均为 0 |
| **范围外（口径不一致）** | 文档/Issue 列为缺口，但不在本 Agent 六地区范围，或与最新总账口径冲突 |

可读性字段：`Y` 可读、`N` 不可读/占位、`Partial` 部分可读、`N/A` 不适用。

### 3.7 国考2024 副省级 q12：C 选项是异版差异，不是简单缺项

  - D 军官分类（正确）

  - A 军官分类
  - B 军衔“**收回**”（错误）
  - C 军事训练保险
  - D “**融资**优惠”
  - 答案 B。
