# 行测「没有答案」的题到底在哪 · 2026-10-26

## 结论

**全库行测 742 卷 / 86,867 道题，每一道题的解析块里都有一条非空答案；答案行整条缺失 0 处、写了空值 0 处。**

真正拿不出答案的只有 **64 卷 / 291 题**，而且这 291 题在本地 md 里全部是同一个固定句式：

```
### 第 N 题

粉笔暂未收录本题（来源缺题，题位保留）

<details><summary>第 N 题 · 答案与解析</summary>

**答案状态：unknown（来源未提供）**

**解析状态：unknown（来源未提供）**

</details>
```

这不是抓漏。**粉笔自己那一页就是空的**：题位在（题号连续、答题卡能跳过去），但题干正文被替换成「题目正在全力以赴征集，将会在第一时间上传（正确答案默认设置为 A 项。）」，A/B/C/D 四个选项的文字分别是「缺失」或「暂缺」。2026-10-26 现场复核 7 卷，粉笔返回的占位题号与本地 md 记的题号逐一对上（第 3 节）。

## 1. 判定口径

按 `### 第 N 题`（第三方卷的 `## 第 N 题` 也算）逐题切块，在块内找答案标签行：

| 形态 | 例子 | 判定 |
|---|---|---|
| 同行取值 | `**答案**：D` | 有答案 |
| 下一行取值 | `**参考答案（粉笔题库参考内容）**` + 空行 + `D` | 有答案 |
| 状态标记 | `**答案状态：unknown（来源未提供）**` | 无答案 |
| 空值 | `**答案**：` / `**答案**：缺失` | 无答案 |

| 项 | 值 |
|---|---:|
| 行测卷 | 742 |
| 题 | 86,867 |
| 答案行缺失 | **0** |
| 答案行空值 | **0** |
| 来源侧无此题（占位） | **291**（64 卷） |

> 早前报表里出现过「某卷只有 2 处参考答案」这类说法，那是只匹配了粉笔口径的 `**参考答案（粉笔题库参考内容）**` 标签，把第三方卷的 `**答案**：D` 和「答案另起一行」的粉笔老格式都漏掉了，**不能用来判断缺答案**。本页改用按题切块 + 多形态匹配。

另有 3 题（新疆2021 第110题、青海2022 第110题、广东2021乡镇 第90题）挂着「本题材料粉笔暂未收录（来源缺题，位置保留）」。核到底：这三处都是**整套资料分析材料缺失**，其后的 5 道题早已按占位计入上表 291 题，不是第 292 道。
