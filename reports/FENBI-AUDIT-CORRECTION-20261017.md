# 更正：粉笔「未征集占位存根」被我误判为「内容不符」（2026-10-17）

本文件**撤回并更正** PR #27 与 PR #29 中的两处结论。仅含身份、数量与状态，不含题目正文、答案、解析或账号资料。

## 1. 我错在哪里

在第二批（PR #27）与第三批（PR #29）中，我把对齐器给出的 `unmatched / no-safe-unique-match`
直接解读为「源与库**内容不一致**」，并据此写出：

- （PR #29）江苏2025C 的 12 处「补录文本与粉笔 C 类原卷内容不符」，并称其为"来自 C 卷实站正文的直接证据"；
- （PR #27、PR #29）江苏2024A 的 4 个缺号与广东2020 的 7 个缺号"**在粉笔真实存在且可见**"。

**这两条都是错的。** 我犯的错误是：**把粉笔的「未征集」占位存根当成了真题正文**。

## 2. 实际证据

在那些题号处，粉笔页面显示的并不是题目，而是同一句占位文案：

> 「题目正在全力以赴征集，将会第一时间上传」（19 字）
> 「题目正在全力以赴征集，将会在征集到后第一时间上传」（24 字）

即粉笔**自己尚未征集到**这些题，只有一个存根。对齐器因此正确地给出 `no-safe-unique-match`
（无可安全唯一匹配），而它**并不表示"两边内容不同"**。

## 3. 更正后的结论

### 3.1 江苏2025C
**粉笔在该 12 个题号处没有任何内容。** 因此：

- 库内那 12 道"据同题公开题本补录"的题，**既不能被粉笔证实，也不能被粉笔证伪**；
- 本仓另一 lane（missing25 / PR #21）关于"补录来源证据不可达"的关切**依然成立且未被本批次解决**；
- 但我此前"补录内容与 C 类原卷不符"的说法**无证据支撑，予以撤回**。

### 3.2 江苏2024A
4 个缺号（76/96/110/111）在粉笔处**同样是占位存根，不是可见真题**。
"粉笔存在且可见、可作补齐来源"的说法**撤回**：粉笔目前**无法**提供这 4 题。

### 3.3 广东2020县级
- 69–75 这 7 个号在粉笔处是**占位存根** → 同样**不能**作为补齐来源（撤回原说法）。
- **但另有 14 处是真实的内容差异**（18,22,64,66,67,79,87,91,92,94,96,98,99,100）：
  逐条核验均为**真题正文**（题干 21–220 字、4 个选项，其中 8 条带材料），**不是占位**。
  这 14 处**仍是需要人工逐项复核的真实差异**，此结论**维持不变**。

## 5. 跨卷图片（此前被怀疑的 81/85）

实测：三卷之间**存在 3 张按字节相同的图片**，出现在 江苏2025C 与 江苏2024A 之间。
但经逐张绑定：

- 它们位于**两个文本不同的材料**中（江苏2025C 材料正文 1238 字 / 江苏2024A 188 字），
  分属 江苏2025C 第 46–50 题与 江苏2024A 第 131–135 题；
- **这 3 张图与 江苏2025C 的那 12 个占位号无关**（占位号处 `imgs=0`、无材料）；
- 也**不在** 81/85。

结论：跨卷图片复用**确实存在**，但**既不能支持"12 题自 A 类供体复制"的假设，也不是 81/85 问题**。
其成因（粉笔通用配图或数据问题）**未定，保留为待查**，本批次不给结论。
