## 口径与限制

- 引用解析：相对 Markdown 所在目录，URL 编码按本地路径处理；带 `#`/`?` 的路径截断后再判存在。正则同时匹配 `![]()` 与 `<img src>`。
- 断图只统计“本地、图片扩展名、文件不存在”；外链、绝对路径、非图片扩展名单列。本次四类计数均为 0。
- 抽取完整性验证：manifest 1,422 卷逐卷的实测引用数与其 `image_references` 字段 100% 一致（84,914 条 Markdown + 1,944 条 HTML = 86,858），且 `![` 出现次数与内联引用数相等，未发现漏解析的引用语法。
- 解析器**不跳过 fenced code block / 行内代码**。这对 manifest 试卷无影响，但会把 `docs/` 中的示例、占位符当成引用，产生上述 8 处文档级假断图；它们已排除在统计之外。
- 孤儿判定依据仓库内全部 `.md`（含 docs、reports）中解析后真实存在的引用，而非仅 manifest；若有构建脚本按目录整体打包图片，则不在本审计的“引用”定义内。已检查 `tools/`、`deploy/`：图片导出按引用逐张复制（`tools/gwyzhenti/export.py`），没有整目录消费 `图片/` 的逻辑。
- 重复按 sha256 内容分组；多路径为硬链接时不重复计可回收空间（本次 `图片/` 无硬链接）。可回收字节是工作区表观大小，不等于 Git 包体积。
- 跨库内容比对：对正文实际引用的 76,037 个文件全部计算 sha256（805.2 MiB、34,593 个唯一哈希），用于判断孤儿内容是否另有副本。
- 未检查图片像素内容是否损坏或与题目语义匹配；仅确认抽样文件 PNG 魔数有效、全目录无 0 字节文件。未对断图做自动修复。
- 快照时点：审计运行于 2026-10-23 13:31 左右，扫描到 1,524 个 Markdown。运行后仓库新增了 `catalog/INDEX.md`、`reports/README.md` 等非图片文档，不影响任何引用、孤儿或重复结果；复跑时除 `all_markdown_files` 计数外 summary 完全一致。
