# 144 候选 · 入库规范审计与决策

## 1. 已读规范

- `docs/QUALITY-STANDARD.md`：真实考试及明确标注的回忆版可归档；来源原缺须如实留位，不得把部分题本伪装成完整整卷；多源冲突保留出处；`0` 条机器错误不等于逐字验真。
- `docs/SCHEMA.md`：一份卷 = 一个 `.md` + 图片；非粉笔来源可用 `命题形式`、`来源明细`、`实有题数`、`缺失原题号`、`分卷核对证据` 等字段；多源用 `来源清单`。
- `catalog/uncollected-slots.jsonl` + `tools/gap_report.py`：已收录来自 manifest；缺卷/待核来自本文件；部分卷的“粉笔暂未收录”占位会计入行测缺题干（A1）；缺口数字必须由生成器计算。
- `资料缺失/`：整卷层占位，不是题本，不能与题级缺口相加。

## 2. 规范是否允许“部分题本/回忆版”

**允许，但只作为“已归档 · 来源原缺”**：必须有真实考试身份、明确来源性质、完整保留缺题编号/缺图状态，并把缺题位置写成占位；不得标“来源范围完整”。部分卷的占位会被 `gap_report.py` 真实计入缺题干，不能手工调数。

## 4. 为什么本轮 0 写入

1. **四个目标卷在 main 都没有正式题本**：兵团2022/2023 是待核/缺卷，宁夏2022/内蒙古2024 是缺卷；`source_fill.py` 需要已有卷+占位题，无法直接写。
2. **题量/缺段未统一**：103 vs 104、121 vs 125、115 vs 102、72 vs 未知；建部分卷必须先选一个总数，当前没有官方题本可裁。
3. **部分卷会把大量源缺项计成新的缺题干**：按候选数反推，四卷分别会新增约 30/78/97/未知 个占位；这是真实口径，但会显著改变缺口统计，需维护者明确同意“以部分卷入库”。
4. **跨省答案不是官方答案**：宁夏47/兵团2022 18 的答案是 0709/0326 联考同题答案，写入时必须逐题注明映射性质；不能写成“宁夏/兵团官方答案”。

因此本轮只产出 **144 条 import-ready 记录 + 412 行审计**，不改题卷、不改槽位、不改缺口统计。维护者若同意建部分卷，可按 `candidates.jsonl` 的 `target_paper/target_q/source_q/stem/options/answer/answer_source/anchors` 生成卷骨架，再用 `source_fill.py` 的 source_snapshot 门禁逐题写入。
