## 六、本轮新增的可运行工具（与本 lane 既有工具不重复）

`tools/fenbi/audit/source_candidate_vet.py` —— **候选来源预检闸门**（区别于 `handoff_reconcile.py`）：

- `handoff_reconcile.py`：已拿到候选后，**逐维度比对库与源**；
- `source_candidate_vet.py`：在比对**之前**回答"这份候选到底有没有这 42 题"。

能力：

| 能力 | 说明 |
|---|---|
| 缺号清单 | **从 front matter 读取**，不硬编码；manifest 变了工具自动跟随 |
| 逐号分类 | `content` / `stub`（未征集占位）/ `absent` / `not-supplied` |
| 判据 | **只有 `content` 才算取回**；`stub` 一律不计为部分修复 |
| 卷型身份 | 检查候选是否含 `2026`/`江苏`/`行测` 标识；不符即标记 |
| 上下文 | 跨连续缺号向外找最近存留题，给出推测题型 |
| 输出 | 五个缺段、逐题状态、汇总 verdict |

verdict 取值：`blocked-no-source-supplied` / `candidate-covers-all-gaps` /
`candidate-covers-some-gaps` / `no-recoverable-content-stub-present` / `candidate-lacks-the-gaps`。

### 顺带修掉一个真实解析缺陷

本卷是**全库唯一**使用裸 `A.` 选项行（而非 `- **A**.`）的行测卷。
共享解析器原先对它返回 **0 个选项**——一旦真有来源，逐维比对会在选项维度上全盘出错。
已在 `_common.parse_paper` 增加回退分支（仅当主格式命中 <2 时才启用，且要求标签严格按
A,B,C,D 顺序以免把普通大写开头的句子误判为选项）。修复后本卷 84/93 题正确解析出 4 个选项，
**其余四卷抽样结果不变**。
