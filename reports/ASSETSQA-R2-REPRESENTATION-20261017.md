## 3. 7 幅图 height 差 1px：是**声明取整**，不是内容问题

| 项 | 实测 |
| --- | --- |
| 有声明尺寸的图（广东） | 37 |
| 宽 `declaredW == trueW` | **37 / 37（100%）** |
| 高精确 | 30 |
| 高差 −1 | **7** |
| 尺寸分歧（width 或 height 差 > 2） | **0** |
| 7 张中**字节等于粉笔采集原图** | **6 / 7**（1 张不在采集集内） |

7 张全部是 **700px 封顶宽**的题目图；另外 7 张同样 700 宽的图则是精确的。也就是说：
**声明高按某一缩放基准做了取整（floor），而实际落地图用的是另一取整（round）**，只在该批次 700 宽图上偶然差 1。

**结论**：
- ✅ 是**框架/取整计算误差**（capped-width rounding），**不是**内容缺失、**不是**图片被改。
- ✅ 6/7 张图与粉笔原图**逐字节相同**（`878fcbf4…`, `e7ecc69c…`, `ced26541…`, `76834327…`, `d47ab67f…`, `37442ec6…`）。
- 低危、纯显示属性；**不应**被报告为内容问题，也不应触发人工看图。

## 4. 41 道图形题：选项图**结构性**无法逐张匹配

### 4.1 结构事实

图形推理题在**源侧**就是：**1 张合成栅格 + 4 个文本等于标签字母的选项**（`A. A / B. B / C. C / D. D`）。仓库**如实镜像**了这一形态。

### 4.2 合成图**是可切的**（新证据）

用递归 XY-cut 做连通块切分（纯结构测量，**不做语义判断**）：

≫ 5–6 块与「1 题干图 + 4 选项图」或「2 题干图 + 4 选项图」的版式吻合。

**结论**：
- 选项图**在像素上是可以切出来的** → 工具侧**可以**在入库时切分并绑定 A–D；
