## 数据可信度与验收边界

| 级别 | 关注什么 | 通过后能说明什么 |
| --- | --- | --- |
| **L1 · 结构检查** | 文件格式、题号、题块、答案块、图片路径 | 文件结构可解析；**不保证真实内容齐全** |
| **L2 · 来源比对** | 同年同省同卷型、考试日期、题号/题干/图件、参考答案映射 | 已核对范围内的内容可溯源；**不等于官方原件认证** |
| **L3 · 阅读验收** | 实际阅读全文、材料、表格、图片、选项与答案 | 只能为实际检查过的卷或题声明验收，不推及全库 |

例如：[深圳 2020 行测1 第 7 题](省考/深圳/2020/行测-行测1.md)题干存在但四个选项全缺；[江苏 2024 行测 C 第 110 题](省考/江苏/2024/行测-C类.md)的「B」是临时默认值；[青海 2020 行测 B 第 28 题](省考/青海/2020/行测-B类.md)中的「缺失」却是**真实选项**，不能被缺选项脚本误判。具体 [阅读检查](docs/READING-QA-20261029.md) 与 [内容深查](docs/CONTENT-QA-20261029.md) 均保留核对依据。

## 仓库结构与维护

| 路径 | 用途 |
| --- | --- |
| `国考/<年份>/`、`省考/<地区>/<年份>/` | 按卷型保存的整卷 Markdown，图片可在同级 `assets-*` 或 `图片/` |
| `catalog/INDEX.md`、`catalog/manifest.jsonl` | 逐卷导航、题数/图片/文件哈希清单 |
| `docs/` | 当前覆盖、缺口、验收标准与技术说明 |
| `reports/` | 按日期保存历史过程及来源证据；**老报告数字不可自动当作当前值** |
| `资料缺失/` | 缺卷及待核槽位的**索引占位**，不是试卷正文 |
| `tools/` | 采集、渲染、检查和统计脚本 |

结构与图片引用检查：

```bash
python3 tools/cloud_quality.py --check --verify-images
```

**维护纪律：** 新统计必须标注 Git 基线、逐题明细和去重规则；原题补录必须有同卷同题证据。不得用其他卷型拼题、默认答案、模考、AI 仿写或无来源内容填补缺口。

第三方题本、参考答案和图片的真实性、版权及再次分发许可尚未逐项核实。详见 [来源与许可说明](docs/SOURCES.md)。
