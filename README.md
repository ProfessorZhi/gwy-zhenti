### 如何直达一题

- 打开整卷链接后，利用 GitHub 文档大纲或题头旁的锚点图标跳转到「第 N 题」；也可以在页面中搜索题号。
- 题头同时存在 `### 第 N 题` 和 `## 第 N 题　<sub>qid …</sub>` 等旧格式，**不应假设每份卷的固定 URL 片段都是 `#第-N-题`**。以 GitHub 实际生成的题头链接为准。
- `<details>` 展开的是参考答案/解析；如果正文声明「来源未提供」「正在征集」，那不是已核实答案。
- 行测图形题使用 Markdown `![](...)` 或 HTML `<img src="...">` 两种相对图片写法，不能只统计其中一种判定缺图。部分源卷还有 Markdown 表格、公式转写内容。

**直连的含义是跳到 GitHub 仓库中的完整 Markdown 文件，不是独立在线刷题系统或官方题库链接。** 文件存在与链接可解析已抽样核对；不同客户端的视觉渲染仍以实际打开页面为准。

## 来源、复现与限制

本库以第三方题库回忆版、公开整理件及多来源补录为主，**不保证官方题序或答案权威性**。第三方全文和图片的再次分发许可尚未逐一核实；公开仓库内可见不等于已经取得转载授权。相关风险与来源性质详见 [来源与许可](docs/SOURCES.md)。

对结构和图片引用做本地检查：

```bash
python3 tools/cloud_quality.py --check --verify-images
```

可复现的数据统计应同时列出检查的 **Git SHA、原始文件数、实际题位数、声明题数、正本排除清单及缺口逐题明细**，不能把历史机器报告里的「来源有的字段未丢」误读为「每道原题都已收齐」。

> **维护原则：先保留真实缺口，找到同卷同题、来源和图片证据后再补入。不得以跨卷拼题、默认答案、模考或不明来源内容填满占位。**
