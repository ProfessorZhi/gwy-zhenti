# 全量排版静态/语义检查器（gwy_format）

只读、离线、单进程。对仓库里每一份 `行测-*.md` / `申论-*.md` 检查 Markdown 的阅读结构：
frontmatter、标题层级、折叠答案、选项分行、材料导航、列表/表格、HTML 转义、超长行、图片引用、
题目目录。**只判结构与排版，不改正文与答案字节。**

> 本次基线跑的是 `main = efea3003…`，仅作当前快照的机器基线；
> **缺口恢复后冻结的 SHA 必须由 R0 重跑本脚本**，不能把这份基线当最终验收。

## 模板感知（为什么不是一套规则套全库）

实测 1850 卷有四种版式，检查器先判模板，再按模板解释"什么叫整齐"：

| 模板 | 卷数 | 形态 |
|---|---:|---|
| `fenbi` | 1839 | `## 题目` + `### 第 N 题` + 每题 `<details>` |
| `mixed-level` | 9 | 资料分析题用 `### 第 N 题` 挂在 `## 材料 N` 下，其余题用 `## 第 N 题` |
| `qid-h2` | 2 | 每题一个 `## 第 N 题　<sub>qid …</sub>`，无折叠块（外部题面克隆） |

同一卷内部风格一致 = 变体；**同一卷内部风格混用 = 问题**（例如选项写法、折叠块写法、材料标题层级）。

## 规则与级别

级别语义：`error` 渲染会坏或语义错；`warn` 明显不整齐但不影响渲染；
`review` 需要人看一眼（可能是有意为之）；`info` 不是缺陷（占位/变体）。

| 码 | 级别 | 检查 |
|---|---|---|
| FM001–FM009 | error/warn | frontmatter 缺失/未闭合/缺字段/科目非法/年份非四位/粉笔卷缺源试卷ID/重复字段 |
| HD001–HD011 | error/review | 无 H1 / 多个 H1 / 标题层级跳跃 / 题号重复 / 题号缺口 / 题号不从 1 开始 / 题目标题层级混用 / 标题以标点结尾 / 空标题 |
| DT002–DT011 | error/warn/review | `<details>` 不配对 / 摘要题号与所在题不一致 / 同题重复折叠块 / 折叠块为空 / 重复「**解析**」/ 题无折叠块（仅在摘要声明"答案随题折叠"时）/ 折叠块写法混用 |
| OP001–OP007 | error/review | 多个选项同一行 / 选项标签跳号 / 标签重复 / 选项缩进 / 只识别到 1 个选项 / 行测题没有选项行 |
| MT001–MT008 | error/warn/review | 材料标题重复 / 材料编号缺口 / 关联材料指向不存在的材料 / 题干有资料号但无关联材料行 / 关联材料写法异常 / 关联行前缺空行 / 材料标题层级混用 / 材料正文为空 |
| LS001/LS003 | error/review | 制表符缩进 / 列表符号混用 |
| TB001–TB004 | error/warn | 表格缺分隔行 / 分隔行列数不符 / 数据行列数不符 / 表格前后缺空行 |
| ES001–ES005 | error/warn/review | HTML 标签开合不匹配 / 形如 `<b（` 的伪标签 / 残缺实体 `&amp` 无分号 / 代码围栏奇数 / 行内反引号奇数 |
| LX001–LX008 | review/warn | 超长行（>2000 字符）/ 行尾空格 / 连续 3 空行 / 标题紧贴正文 / `<details>` 前后缺空行 / 文件末尾无换行 / CRLF |
| IM001–IM004 | error/warn/review | 图片文件不在仓库 / 远程 URL / 路径含空格 / 图片重复引用 |
| NV001/NV003–NV005 | review/warn | 缺 overview 摘要块 / 导航锚点不存在 / 摘要题数不符 / 摘要图片数不符 |
| PH001 | info | 源征集占位（「暂未收录/来源缺题/题位保留」等），**不算排版缺陷** |

### 有意不报的（实测都是假阳性）

- **列表前无空行**：CommonMark 允许 bullet list 打断段落，渲染仍是列表。
- **`-6，-2，…` / `+小饼…` / `--习近平：`**：是数学符号或引文破折号，不是列表标记。
- **`a<b（12.2%）`**：`<` 后接全角括号不是 HTML 标签（只记 review 提醒）。
- **`|甲-乙|=|丙-丁|`**：单行竖线是数学，不是表格。
- **判断题/填空题**：以「（　）」收尾或短陈述句的题没有 A–D 选项，不是缺选项。
- **`A、B两地…` 开头**：`、` 只在整块没有任何 `.` 式选项时才当选项分隔符。

## 限度

1. 只看 Markdown 结构，不做语义/内容正确性判断（那是 R1 保真审计的范围）。
2. 图片只核"文件在仓库里 + 路径可解析"；不取字节、不比像素。
3. 需要人判断的"视觉层次"（例如 9 卷题目标题层级混用、22 处标题紧贴正文）统一记 `review`，
   不擅自改写。
4. 稀疏检出时用 `git ls-tree` 判断图片是否在树里，避免把"没检出"误判为"缺图"。
