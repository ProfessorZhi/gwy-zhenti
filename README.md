**国考 · 省考｜行测 · 申论｜高质量 Markdown 图文真题**

本仓库以**人类阅读体验和机器准确读取**为共同标准，整理各地区、各年份、各卷型的真实公务员考试试卷。目标是：直接打开 Markdown 就能清楚阅读题目、表格、图形和给定材料；也能让 AI 可靠地引用、定位、检索、讲解每一道题。

> **建设中**：全国真题的导入与逐卷验收尚未完成。这里所说的“全国完整”是长期目标，不是对当前覆盖率的声明。

## 内容范围

- **国考**：行测、申论；副省级、地市级、行政执法等不同卷型独立记录。
- **省考**：各省、自治区、直辖市，含联考及单独命题；A/B/C 类、乡镇类等均保留原试卷区分。
- **年份**：尽可能覆盖历年公开可取得的试卷，并持续更新。
- **不混入**：模考、原创预测题、学习讲义、事业编、选调生；这些与国省考真题属于不同对象。

## 为什么用 Markdown

- **好读**：以原卷为单位，题干、选项、材料、图片、答案、解析布局清晰；长卷有目录，答案不提前泄露。
- **好用**：图形推理和资料分析的图片保存在相对路径下，断网可看；表格尽量用原生 Markdown，公式使用规范数学表达。
- **好查**：每卷元数据统一，题目有稳定锚点，便于 GitHub、VS Code、Obsidian 及 AI 检索。
- **可信**：保留真实来源、版本、原题序号、卷型和核验状态；来源冲突先标注，不自行编造“官方答案”。

## 整理原则

**覆盖用并集，正确性用交叉验证。** 先收集多个上游数据源，各自提取来源清单；相同卷/同一道题去重后保留不同版本引用。两三个仓库若只是同一个源的 fork，不能当成独立佐证。

完整题目、原卷图片和试卷分类优先于题库总量；申论必须保留**完整给定材料与全部作答要求**，不得把浓缩摘要充当原卷。仅在来源与使用许可允许、版面和信息均核验合格后纳入正式题库。质量标准见 [QUALITY.md](QUALITY.md)，候选来源与已知缺口见 [SOURCES.md](SOURCES.md)。

## 交付与同步

本仓的交付物 = **正式 MD + 被这些 MD 实际引用的全部图片**，两者一并入库：

- 图片一律用**相对路径**引用（`<img src="../../图片/<卷名>/题目图/xx.png">`，早期批次有少量
  Markdown 语法 `![](相对路径)`），**不 Base64 内联、不做有损压缩**，保持目录结构与相对路径不变。
- **不入库**：PDF 原件、网盘压缩包、微信原始文件、PDF 转换中间产物、OCR 缓存、
  调试日志与临时脚本产物、密钥与账号信息，以及**未被任何正式 MD 引用的孤儿图片**。
- 入库走**显式文件清单**（`work/qa/DELIVERY-FILES.txt`，本轮 97,154 项 / 653.5 MB），
  不使用 `git add -A`；可分批发提交，不做 force push。
- 图片与 MD 的分级台账：`work/qa/IMG-SET.jsonl`（被引用）、`work/qa/IMG-ORPHAN.jsonl`（孤儿）、
  `work/qa/IMG-REFS.jsonl`（逐份 MD 的引用/断链统计）；正式清单为 `work/manifest.jsonl`。
- **行尾统一为 LF**（`.gitattributes` 已声明 `*.md text eol=lf`）。本轮把 360 份含 `\r` 的文件
  （354 份申论正文用的是上游 Mac 风格 `\r\r\n` 断行）归一化：`\r\n→\n` 再 `\r→\n`，
  并逐份断言 `splitlines()` **行序列完全相等**，所以只统一了行尾字节、段落结构一字未动。
  （若交给 git 归一，`\r\r\n` 会退化成单个行尾、**段落空行被吞**，GitHub 渲染会与本地不一致。）
- `work/` 目录为内部台账，**不入库**；远端交付只含上表所列的 MD、图片与工具文档。

> **再分发权限**：第三方上游的**全文与图片**的转载授权**尚未逐一核实**（各卷 frontmatter 的
> `校验状态` 已逐卷写明）。本仓为**私有仓库**，内容仅供授权范围内使用；未获授权前不公开分发。
