## 试卷格式

每道题后面紧跟一个默认折叠的答案块，作答后再展开查看。以下为 [国考 2025 行测地市级](国考/2025/行测-地市级.md) 第 22 题的实际效果（解析有删节）：

> ### 第 22 题
>
> 下列情形不在申请行政复议范围之内的是：
>
> A. 餐馆甲因食品卫生不达标，被吊销餐饮服务许可证，甲不服
>
> B. 建设单位乙在申请建筑工程施工许可证时，因申请材料不全被拒绝，乙不服
>
> C. 公务员丙不能胜任工作，其所属行政机关作出降职处理决定，丙不服
>
> D. 工人丁提出工伤认定申请，当地人力资源和社会保障局作出不予受理决定，丁不服
>
> <details><summary>第 22 题 · 答案与解析</summary>
>
> **参考答案（粉笔题库参考内容）**
>
> C
>
> **解析**
>
> 本题考查法律常识。……C项错误，根据《中华人民共和国行政复议法》第十二条第三项规定：“下列事项不属于行政复议范围：（三）行政机关对行政机关工作人员的奖惩、任免等决定。”针对公务员丙作出的降职处理决定，不在行政复议范围之内。……本题为选非题，故正确答案为C。
>
> </details>

每份试卷另包括：

- **卷首概览**：题量、题型模块与题号分布、章节导航；
- **材料在题前**：资料分析、篇章阅读的材料紧挨着对应题组；申论的给定材料全文放在前面，每道题标出“关联材料”；
- **图在原位**：图形推理、图表题的图片和试卷放在同一目录，用相对路径引用，离线也能显示；
- **来源可查**：文件开头写明来源链接、源试卷 ID 和采集时间。

## 说明

- **试卷性质**：内容来自粉笔题库整理版（多为考生回忆版）及少量其他公开题本，未经官方认证；参考答案与解析来自第三方题库，不代表官方答案。
- **缺口处理**：来源缺失的内容保留题位并明确标注，不以其他卷型拼凑，不使用默认答案，不使用 AI 生成内容填补。
- **收录范围**：仅收国考、省考真题，不收模考、预测卷与讲义。
- **版权**：第三方题本、答案解析与图片的转载许可尚未逐项核实，详见 [数据来源与许可](docs/SOURCES.md)。
