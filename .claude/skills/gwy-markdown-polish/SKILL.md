# 公务员真题 Markdown 排版规范

## 这份 Skill 解决什么

仓库里的试卷是**数据**，不是普通文章：题干、选项、答案、解析、图片路径都有下游脚本与
`catalog/manifest.jsonl` 的 SHA-256 在盯。因此排版必须**只改观察到的版式，不改语义内容**。

默认卷面形态（用户 2026-10-23 确认）：

```text
第 1 题
  题干 + A/B/C/D
<details><summary>第 1 题 · 答案与解析</summary>  ← 默认折叠
参考答案 / 解析
</details>

第 2 题
  ……
```

即 **题 → 折叠答案 → 题 → 折叠答案**，读完题伸手就能展开，不必翻到卷末。材料、图表
保持原位（资料分析的材料紧跟对应题组之前）。

## 硬约束（任何时候都不许破）

1. **不改**题干、选项、答案、解析、材料正文的任何字符（含标点、全角半角）。答案块只搬位置。
2. **不改**图片相对路径与文件名；不移动、不下载图片。
3. **不改** YAML frontmatter 的字段名与值。
4. **不改** `### 第 N 题` / `## 第 N 题` 的题号与层级（允许保留 `（文章写作题）`、`<sub>常识判断</sub>` 这类后缀）。
5. 答案与题目必须**按题号一一对应**才能搬；缺一个、重一个、编号对不上就整卷不动，报告原因。
6. 每批改完必须过闸门（见下），改动后刷新 `catalog/manifest.jsonl`。

## 脚本闸门（`tools/polish_markdown.py` 内置）

逐卷写盘前自动核对，任一不符即拒绝该文件：

| 检查 | 要求 |
| --- | --- |
| 题数 `### 第 N 题` / `## 第 N 题` | 不变 |
| 选项行 `^[A-D][.、．]` | 不变 |
| 图片引用数（`![](...)` + `<img>`） | 不变 |
| `<details>` / `<summary>` 数 | 不变 |
| 答案块正文（去外壳的多重集合） | 完全一致 |
| 去掉概览块后的正文 | 与搬移后的正文仅差空白 |

另外吸收了社区 `markdown-formatter` skill 的检查项，作为人工复核清单：标题层级不跳级、
代码围栏成对、表格列数一致、同名标题不重复（GitHub 锚点会被后者覆盖）、空行不连排。

## 卷面骨架

### 行测

```markdown
# 2008年浙江省公务员录用考试《行测》题

<!-- gwy:overview:start -->
> **浙江 · 2008 · 行测 · 统考** ｜ 130 题 · 图片 278 处 · 答案随题折叠

| 题型模块 | 题量 | 题号 |
| --- | ---: | ---: |
| 数量关系 | 25 | 1–25 |
| 言语理解与表达 | 30 | 26–55 |
| **合计** | **130** | |

导航：[题型与作答说明](#题型与作答说明) · [题目](#题目) · [材料 1](#材料-1)
<!-- gwy:overview:end -->

> 候选采集稿。……（原有说明原样保留）

## 题型与作答说明
……

## 题目

### 第 1 题

20，20，33，59，98，![](assets-fenbi-85/xxx.png)。

A. 150

B. 152

C. 154

D. 156

<details><summary>第 1 题 · 答案与解析</summary>

**参考答案（粉笔题库参考内容）**

A

**解析**

……

</details>

### 第 2 题
```

- 概览块放在 H1 之后；用 `<!-- gwy:overview:start/end -->` 包住，**可重复执行**（重跑替换，不叠加）。
- 题型结构表从「题型与作答说明」里的「模块名 + （N题）」成对文本推导，只**新增**表格，
  不重写原有说明文字。推导不出、或合计与题数不符，就只保留概览行，不猜。

### 申论

```markdown
# 2025年浙江公务员考试《申论》试题（A卷）

<!-- gwy:overview:start -->
> **浙江 · 2025 · 申论 · A类** ｜ 3 题 · 图片 0 处 · 答案随题折叠

导航：[给定资料 材料一：](#给定资料-材料一) · [第 1 题](#第-1-题)
<!-- gwy:overview:end -->
```

- 申论不强行造「题型模块」表（材料与作答题不是一一对应）。
- R7 导读块及其 `#r7-reference-N` 锚点原样保留；锚点随答案块搬到对应题目下，链接仍然有效。
- 旧格式 `## 给定资料 材料一：` 只在 `--normalize-material-headings` 打开时才改为 `## 材料一`，默认不动。
- 卷末答案区若有 `> 本轮只补…` 之类说明，搬到「题目」小节开头；若还有 `## 未自动迁移的旧版答案`
  等后续章节，原样留在卷末。

## 空白与分隔

- 行尾空白去掉；连续空行压到 1 行（代码块内不动）。
- 标题行后保证 1 个空行。
- 文件以单个换行结尾。
- `<details>` 内部保持原有空行节奏，不重排。

## 实施方式

```bash
# 1) 先看会改什么（不写盘）
python3 -I tools/polish_markdown.py --check --paths 省考/浙江/2008/行测-统考.md

# 2) 写盘并逐卷自检
python3 -I tools/polish_markdown.py --write --paths 省考/浙江/2008/行测-统考.md

# 3) 小批量（默认 20 份）
python3 -I tools/polish_markdown.py --write --limit 20

# 4) 全量后刷新清单并复核
python3 -I tools/refresh_manifest.py --write --check
python3 -I tools/catalog_index.py --check
```

批量时按 **地区 → 年份** 切片，每批 20–50 卷；多个 agent 可并行处理不同切片，但每批写完后
统一跑一次清单刷新。**不要**并发写同一个文件。

## 不要做的事

- 不要跑 `prettier --write "**/*.md"`：它会把 `<details>`、表格与图片语法重排，
  还可能吞掉题号之间的空行，造成行级 diff 淹没真正的改动。
- 不要为「好看」合并或拆分题目、重排选项顺序、改答案字母。
- 不要把 HTML 折叠块换成 Markdown 引用块：`<details>` 是阅读器与脚本共同依赖的结构。
- 不要为了凑 1:1 而给缺答案的题编造答案，也不要给缺题号的申论臆造题号。

## 已知无法自动搬移的卷（约 32 份）

- 25 份没有 `## 答案与解析` 区（本就没有答案）。
- 6 份只有材料、正文里没有 `第 N 题` 标题（如天津 2023 申论行政执法卷），答案区保持原样。
- 1 份答案区为空。

这些卷仍会加上概览与统一空白，只是答案不随题折叠；报告里标记 `answers-kept:*`。
